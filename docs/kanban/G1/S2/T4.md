# G1.S2.T4: SSE 流式对话

## Task

让个人对话支持流式输出——体验流畅。

1. 在对话面板用 `fetch` + SSE 或 EventSource 消费流式:
   - 请求头: Accept: text/event-stream
   - body: { userId, message }
2. 解析 SSE 事件:
   - `data: {"delta":"..."}` → 逐块追加到回答
   - `data: {"done":true}` → 结束流
   - `data: {"error":"..."}` → 错误
3. 打字机效果: 边收到边显示
4. 流式中断/错误处理
