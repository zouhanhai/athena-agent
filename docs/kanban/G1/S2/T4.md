# G1.S2.T4: SSE Streaming Chat

## Task

Enable streaming output for personal chat — smooth experience.

1. In chat panel, consume streaming via `fetch` + SSE or EventSource:
   - Request header: Accept: text/event-stream
   - body: { userId, message }
2. Parse SSE events:
   - `data: {"delta":"..."}` → append chunk to response
   - `data: {"done":true}` → end stream
   - `data: {"error":"..."}` → error
3. Typewriter effect: display as received
4. Stream interruption/error handling
