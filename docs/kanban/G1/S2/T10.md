# G1.S2.T10: Theme System Refinement (Dark Unified + Light Layering)

## Task

Systematically refine both dark and light theme sets, fixing current UI issues.

## Current Issues

**Dark theme**:
1. Sidebar bottom (footer/Settings area) is white, inconsistent with dark aside
2. Input box (t-textarea) has white background
3. Sidebar middle nav menu protrudes (wider than top/bottom sections)
4. TDesign components (input/menu/dialog) default light, not following dark theme

**Light theme**:
5. All white, no layering distinction between modules
6. Chat panel/input box all pure white, not card-based

## Implementation

### Dark theme
- Override TDesign component variables: `--td-bg-color-component`, `--td-bg-color-container`, `--td-bg-color-page`, input background etc.
- Sidebar footer/Settings area uses `--caleo-sidebar-bg` (dark blue), unified with aside
- Input box dark: override textarea background/text
- Sidebar nav menu: width/style aligned with aside, not protruding

### Light theme
- Layering distinction: background `#f0f1f3` (light gray) + card/panel `#ffffff` (white) + border
- Sidebar light gray, main content area card-based (with border or rounded card)
- Light blue/light gray for hover/selected states

### Chat bubbles
- AI reply bubble vs user send bubble differentiated (dark: AI dark gray/user orange; light: AI light gray/user light blue)

### Component variables
- Systematically override TDesign `--td-*` background/text/border variables (both theme sets)
