# G1.S2.T10: 主题系统完善 (深色统一 + 浅色层次)

## Task

系统性完善深浅两套主题, 修复当前 UI 问题。

## 当前问题

**深色主题**:
1. 侧边栏底部 (footer/Settings 区域) 是白色, 与深色 aside 不统一
2. 输入框 (t-textarea) 是白色底
3. 侧边栏中间 nav 菜单凸出 (比上下部分宽)
4. TDesign 组件 (input/menu/dialog) 默认浅色, 未跟随深色主题

**浅色主题**:
5. 全白, 模块间无层次区分
6. chat 面板/输入框都是纯白, 无卡片化

## 实现

### 深色主题
- 覆盖 TDesign 组件变量: `--td-bg-color-component`, `--td-bg-color-container`, `--td-bg-color-page`, 输入框背景等
- 侧边栏 footer/Settings 区域用 `--caleo-sidebar-bg` (深蓝), 与 aside 统一
- 输入框深色: 覆盖 textarea 背景/文字
- 侧边栏 nav 菜单: 宽度/样式与 aside 对齐, 不凸出

### 浅色主题
- 层次区分: 背景 `#f0f1f3` (浅灰) + 卡片/面板 `#ffffff` (白) + 边框
- 侧边栏浅灰, 主内容区卡片化 (有边框或圆角卡片)
- 浅蓝/浅灰做 hover/选中态

### 对话气泡
- AI 回复气泡 vs 用户发送气泡区分 (深色: AI深灰/用户橙; 浅色: AI浅灰/用户浅蓝)

### 组件变量
- 系统覆盖 TDesign `--td-*` 背景/文字/边框变量 (两套主题)
