# G1.S2.T3: 个人对话面板 (基础)

## Task

实现个人对话面板——核心 MVP 功能。

1. `/chat` 页面 (views/ChatView.vue) 聊天界面:
   - 顶部: 展示当前 userId (MVP 手动输入或默认)
   - 消息区: 滚动列表 (消息文本)
   - 底部: 输入框 + 发送按钮
2. 对接后端:
   - POST /api/chat { userId, message } → { reply }
   - 显示回答
3. 消息状态:
   - user 消息 (右对齐)
   - assistant 回复 (左对齐)
4. 发送时禁用按钮 + loading 状态
