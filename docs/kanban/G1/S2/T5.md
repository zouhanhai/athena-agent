# G1.S2.T5: API Client + Pinia State Management

## Task

Encapsulate API layer and state management, making chat functionality cleanly structured and reusable.

1. `src/api/chat.ts`:
   - `sendChat(userId, message)` → non-streaming { reply }
   - `streamChat(userId, message, onDelta)` → streaming (callback per chunk)
   - Error handling
2. Pinia store (`src/stores/chat.ts`):
   - state: messages, loading, error, userId
   - actions: send (calls api), reset
3. Refactor chat panel to use store (replace T3/T4 direct API calls)
4. Convention: components don't call API directly, go through store
