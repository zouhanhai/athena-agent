# G1.S2.T7: 侧边栏设置面板 + 深浅主题切换

## Task

修复主题不一致 (侧边栏深色但主体白色), 并添加主题切换功能。

**当前问题**:
- SidebarNav 深蓝 (#2d3142), 但 App.vue 的 .app-content 硬编码 #f5f6f7 (浅色)
- 主体白底与深色侧边栏不统一
- theme/index.ts 定义了 caleoThemeVars 但只绑在 t-layout, 不够全局

**实现**:
1. 侧边栏底部加"设置"按钮 → 打开弹层/抽屉
2. 设置面板含主题选择 (深色 Dark / 浅色 Light)
3. 全局主题系统:
   - 定义深色/浅色两套 CSS 变量 (背景/文字/边框)
   - 应用到 html/body 全局 (不只 t-layout)
   - 侧边栏 + 主体统一配色
4. 主题状态用 Pinia store (或 composable) + localStorage 持久化
5. 默认主题: 深色 (当前品牌方向)
