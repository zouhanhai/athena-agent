# G1.S2.T7: Sidebar Settings Panel + Dark/Light Theme Toggle

## Task

Fix theme inconsistency (sidebar dark but main content white), and add theme toggle functionality.

**Current issues**:
- SidebarNav dark blue (#2d3142), but App.vue's .app-content hardcoded #f5f6f7 (light)
- Main content white background inconsistent with dark sidebar
- theme/index.ts defines caleoThemeVars but only bound to t-layout, not global enough

**Implementation**:
1. Add "Settings" button at bottom of sidebar → opens popover/drawer
2. Settings panel includes theme selection (Dark / Light)
3. Global theme system:
   - Define dark/light two sets of CSS variables (background/text/border)
   - Apply to html/body globally (not just t-layout)
   - Sidebar + main content unified colors
4. Theme state via Pinia store (or composable) + localStorage persistence
5. Default theme: dark (current brand direction)
