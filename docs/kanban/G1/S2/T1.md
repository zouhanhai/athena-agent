# G1.S2.T1: 前端项目脚手架 (Vue3 + Vite + TDesign)

## Task

1. 创建 `web/` 目录（前端根目录）
2. 初始化 Vue3 + Vite + TypeScript 项目

4. 创建基础入口（main.ts + App.vue）
