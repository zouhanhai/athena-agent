# G1.S2.T9: Chat Input Box Multi-line Optimization

## Task

Optimize the Chat page bottom input box — currently narrow single-line, change to slightly wider multi-line.

**Current state**: ChatView.vue bottom uses `t-input` (single line), layout is flex row (input+send button)

**Implementation**:
1. Change input box to textarea (multi-line):
   - TDesign uses `t-textarea` (or t-input type=textarea)
   - Can display multi-line content
2. Width/height adjustment:
   - Slightly wider than current, height 2-3 lines (auto-grow)
3. Send experience:
   - Enter to send, Shift+Enter for newline
   - Or keep send button
4. Coordinate with send button/layout
