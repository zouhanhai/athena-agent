# G1.S2.T9: 对话输入框多行优化

## Task

优化 Chat 页底部的输入框——当前是窄长单行, 改为稍宽多行。

**现状**: ChatView.vue 底部用 `t-input` (单行), 布局是 flex 一行 (输入框+发送按钮)

**实现**:
1. 输入框改为 textarea (多行):
   - TDesign 用 `t-textarea` (或 t-input type=textarea)
   - 能显示多行内容
2. 宽度/高度调整:
   - 比当前稍宽一点, 高度 2-3 行 (auto-grow)
3. 发送体验:
   - Enter 发送, Shift+Enter 换行
   - 或保留发送按钮
4. 与发送按钮/布局协调
