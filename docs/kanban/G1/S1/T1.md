# G1.S1.T1: Project Init + Pi SDK Dependency Installation

## Task

Establish the Pi-centric backend project skeleton in athena-agent.

**Note**: This project's engine is Pi SDK (@earendil-works/pi-coding-agent); Fastify is just an HTTP thin shell. First build a runnable foundation.

1. Create `server/` directory (backend root)
2. `npm init` + install dependencies:
   - `fastify` (HTTP framework)
   - `@earendil-works/pi-coding-agent` (Pi SDK core)
   - `typescript` + `ts-node` or `tsx` (TS runtime)
   - `@types/node`
3. Configure `tsconfig.json` (strict: true, esModuleInterop)
4. Create `server/src/index.ts`: minimal Fastify service, listen on port, provide `GET /health` returning `{status:"ok"}`
5. Verify: `npm install` + service can start + `GET /health` returns 200
