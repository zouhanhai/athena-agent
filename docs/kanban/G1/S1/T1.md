# G1.S1.T1: 项目初始化 + Pi SDK 依赖安装

## Task

在 athena-agent 建立以 Pi 为核心的后端项目骨架。

**注意**: 本项目的 engine 是 Pi SDK（@earendil-works/pi-coding-agent），Fastify 只是 HTTP 薄壳。先搭能跑通的基础。

1. 创建 `server/` 目录（后端根目录）
2. `npm init` + 安装依赖:
   - `fastify`（HTTP 框架）
   - `@earendil-works/pi-coding-agent`（Pi SDK 核心）
   - `typescript` + `ts-node` 或 `tsx`（TS 运行时）
   - `@types/node`
3. 配置 `tsconfig.json`（strict: true, esModuleInterop）
4. 创建 `server/src/index.ts`：最小 Fastify 服务，监听端口，提供 `GET /health` 返回 `{status:"ok"}`
5. 验证: `npm install` + 服务能启动 + `GET /health` 返回 200
