# G1.S1.T2: AgentSession 集成 + POST /api/chat

## Task

在 Fastify 后端集成 Pi 的 AgentSession，提供个人对话 API：

1. 安装 @earendil-works/pi-coding-agent
2. 在 `server/src/agents/` 创建 AgentSession 管理（每员工常驻实例的雏形）
3. 配置对话模型（DeepSeek，经 opencode-go 或直接 DeepSeek API）
4. 创建 `server/src/routes/chat.ts`：POST /api/chat
   - 请求: { message, sessionId? }
   - 响应: Pi 的回答（可流式）
5. 连接 AgentSession 处理消息
