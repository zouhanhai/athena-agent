# G1.S1.T2: Pi SDK 集成骨架 (createAgentSession 跑通)

## Task

验证 Pi SDK 能在 athena 后端内嵌并工作。这是 athena 的核心引擎验证。

1. 在 `server/src/agents/` 创建 `agent.ts`：
   - 用 `createAgentSession()` 创建会话
   - 用 `ModelRuntime.create()` 初始化模型运行时
   - 配置 DeepSeek 模型（opencode-go/deepseek-v4-flash 或 DeepSeek API）
2. 写一个最小验证脚本：创建 session → `prompt("hi")` → 打印回答
3. 确认能加载已安装的 Pi packages（简单验证 memory/intercom 不报错）
4. 封装一个复用函数（如 `createAgent()`），供后续每员工实例使用
