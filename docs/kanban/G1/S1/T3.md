# G1.S1.T3: AgentSession Management Module (Per-Employee Instances)

## Task

Implement multi-employee session management — each employee gets an independent, isolated AgentSession.

1. Create `AgentManager` class in `server/src/agents/manager.ts`:
   - `getAgent(userId)`: get or create the user's AgentSession
   - `removeAgent(userId)`: destroy the session
   - Internally managed with Map<userId, AgentSession>
2. Use Pi's `SessionManager` for persistence (inMemory or file)
3. Per-employee independent instances (isolated memory/context/model state)
4. Handle concurrency: same employee repeated requests reuse the same session
5. Write unit tests verifying: different employees → independent sessions; same employee → reuse
