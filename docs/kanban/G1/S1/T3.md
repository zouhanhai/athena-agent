# G1.S1.T3: AgentSession 管理模块 (每员工实例)

## Task

实现多员工会话管理——每个员工一个独立的护带 AgentSession。

1. 在 `server/src/agents/manager.ts` 创建 `AgentManager` 类：
   - `getAgent(userId)`: 获取或创建该用户的 AgentSession
   - `removeAgent(userId)`: 销毁会话
   - 内部用 Map<userId, AgentSession> 管理
2. 用 Pi 的 `SessionManager` 持久化（inMemory 或文件）
3. 每员工独立实例（隔离内存/上下文/模型状态）
4. 处理并发：同一员工重复请求复用同一 session
5. 写单元测试验证: 创建不同员工 → 独立 session; 同员工 → 复用
