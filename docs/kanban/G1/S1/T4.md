# G1.S1.T4: POST /api/chat Chat Endpoint

## Task

Implement the HTTP API for personal chat — forwarding frontend requests to Pi AgentSession.

1. Create route `POST /api/chat` in `server/src/routes/chat.ts`:
   - Request body: `{ message: string, userId: string }`
   - Use AgentManager.getAgent(userId) to get the session
   - `await session.prompt(message)` to process
   - Forward streaming response via `session.subscribe()`
   - Return Pi's response
2. Support both streaming (recommend SSE: `text/event-stream`) and non-streaming modes
3. Mount to Fastify app (register route in server/src/index.ts)
4. Verify: curl POST /api/chat returns a response
