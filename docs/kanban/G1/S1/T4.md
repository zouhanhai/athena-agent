# G1.S1.T4: POST /api/chat 对话端点

## Task

实现个人对话的 HTTP API——把前端请求转给 Pi AgentSession。

1. 在 `server/src/routes/chat.ts` 创建路由 `POST /api/chat`：
   - 请求体: `{ message: string, userId: string }`
   - 用 AgentManager.getAgent(userId) 获取会话
   - `await session.prompt(message)` 处理
   - 通过 `session.subscribe()` 转发流式回答
   - 返回 Pi 的回答
2. 支持流式（推荐 SSE：`text/event-stream`）+ 非流式两种
3. 挂载到 Fastify app（server/src/index.ts 注册路由）
4. 验证: curl POST /api/chat 能拿到回答
