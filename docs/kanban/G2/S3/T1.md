# G2.S3.T1: Backend Knowledge Service Layer

## Task

Build the backend knowledge service layer encapsulating both knowledge sources.

## Implementation

### 1. kb/lightrag.ts
- `getHealth()`: GET :9621/health
- `ingestText(text)`: POST /documents/text (LightRAG ingestion)
- `query(query)`: POST /query (semantic retrieval)
- `getGraph(label)`: GET /graphs?label=X → {nodes, edges}

### 2. kb/llmwiki.ts
- `listProjects()`: GET :19828/api/v1/projects
- `getFileTree(projectId, dir)`: GET /projects/{id}/files
- `readFile(projectId, path)`: GET /projects/{id}/files/content
- `search(projectId, query)`: POST /projects/{id}/search (hybrid keyword+vector+graph)
- `getGraph(projectId)`: GET /projects/{id}/graph → {nodes, edges}

### 3. Tests
- node:test, mock the HTTP calls (nock or injected fetch)
- Verify against live services where possible (llm_wiki :19828, LightRAG :9621)
