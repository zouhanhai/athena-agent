# G2.S5.T8: Retry Button for Failed Pipeline Stages

## Problem

When one pipeline fails (e.g. LightRAG failed but llm_wiki done), the task shows a
failed status with no way to retry — the user must Remove and re-upload the whole file,
wasting the already-successful stage.

## Implementation

1. **Backend** (`server/src/kb/tasks.ts` + `server/src/routes/kb.ts`):
   - Add `retry(taskId)` to `IngestTaskQueue`: re-run only failed stages, keep done stages
   - Add `POST /api/kb/ingest/retry` body `{ taskId }` → returns updated task
2. **Frontend** (`web/src/views/KnowledgeView.vue`):
   - For a task with `status === "failed"`, show a "Retry" button next to "Remove"
   - On click → POST /api/kb/ingest/retry → poll task again
3. **Tests**: unit test retry endpoint (failed stage re-runs, done stage untouched)
