# G2.S5.T3: Frontend Add Data Area + Progress Bar

## Task

Add the data/document input UI to the Knowledge panel (not a new tab/page) with per-source progress tracking.

## Implementation

### 1. Add Data Area (KnowledgeView.vue — inside existing panel)
- **No new tab/page**: the Add Data area is a section within KnowledgeView.vue, alongside the 2D graph (S4.T2)
- File drag/drop/select zone (accept docling formats)
- URL input box (paste URL → ingest)
- Supported format hints (PDF/DOCX/XLSX/PPTX/images/HTML/EPUB/CSV/Markdown)
- Calls `/api/kb/ingest` (multipart) + `/api/kb/ingest-url`

### 2. Progress Bar (per-system stages)
- Per-source task list with progress:
  - Stages: parsing (docling) → ingesting LightRAG → ingesting llm_wiki → done / failed
  - Show per-system status (LightRAG ok / llm_wiki ok/failed independently)
  - Poll `GET /api/kb/task/:id` (interval) while active
- Use TDesign Progress component

### 3. Design consistency (mandatory)
- Follow existing CALEO design language:
  - `--caleo-*` + `--td-*` CSS variables (no hardcoded colors)
  - Card layout matching `.chat-panel` (header + body)
  - Orange brand + sky accents, dark/light theme aware
  - Reference ChatView.vue + theme/index.ts
