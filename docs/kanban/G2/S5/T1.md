# G2.S5.T1: docling Unified Parsing Layer

## Task

Set up the docling-based unified document parsing layer on 6900XT.

## Implementation

### 1. Install docling
- `pip install docling` (Python 3.12, 6900XT)
- Verify supported formats (PDF/DOCX/XLSX/PPTX/images/HTML/EPUB/CSV/Markdown/URL)

### 2. Parse script (shared input-dir)
- Script: `parse_doc.py <input> <output-dir>`:
  - Accepts file path or URL
  - docling → Markdown output
  - Writes to shared input-dir (e.g. ~/lightrag/inputs + llm_wiki wiki dir, or a staging dir)
- Handles all docling-supported types
- (Optional) legacy DOC/XLS/PPT via LibreOffice if needed

### 3. Verification
- Parse a sample PDF, DOCX, XLSX, PPTX, image, HTML → all produce valid Markdown
- URL parse works (docling fetches web page → Markdown)
