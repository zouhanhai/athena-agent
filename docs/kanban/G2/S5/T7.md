# G2.S5.T7: LightRAG Graph Empty Fix

## Problem

Frontend Knowledge graph shows "0 entities · 0 links" (empty), but LightRAG has a
populated graph (272 nodes / 353 edges). Root cause: backend `server/src/kb/retrieval.ts`
defaults `lightragLabel = "all"`, which is NOT a valid LightRAG label — `label=all` returns
empty. LightRAG needs `label=*` to return the full graph.

## Verification
- `GET /api/kb/graph` (via /api/kb/graph) currently → `{"nodes":[],"edges":[]}`
- Direct `GET :9621/graphs?label=*` → 272 nodes / 353 edges

## Implementation
1. Change default `lightragLabel` from `"all"` to `"*"` in `server/src/kb/retrieval.ts`
2. Verify `/api/kb/graph` returns the full graph (nodes + edges)
3. Frontend Knowledge graph panel renders the entity graph
4. (Optional) support label param to filter graph by entity type

## Reference
- `docs/knowledge-rag-design.md`
- `server/src/kb/retrieval.ts` (getGraph)
- `docs/kanban/G2/S4/T2.md` (Knowledge graph panel)
