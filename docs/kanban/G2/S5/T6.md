# G2.S5.T6: docling Picture Descriptions

## Problem

docling parses PDF images as `image` placeholders without text descriptions, losing
information that lives in images. Enable docling's picture-description VLM feature so
image content is captured in the ingested Markdown.

## Implementation

1. **Enable picture descriptions in parse_doc.py**:
   - `pipeline_options.do_picture_description = True`
   - Configure VLM via `PictureDescriptionApiOptions` pointing to
     `qwen/qwen3.7-flash` on OpenRouter (`https://openrouter.ai/api/v1`, key in ~/.bashrc)
2. **Verify** on a PDF with images: markdown contains image descriptions
   (e.g. "Figure: ...") instead of bare `image` placeholder
3. **Test**: ingest a PDF with images → both LightRAG + llm_wiki capture image text

## Reference
- `docs/kanban/G2/S5/Spec.md`
- `server/scripts/parse_doc.py` (current parser)
- docling picture description: `PdfPipelineOptions.do_picture_description` + `PictureDescriptionApiOptions`
- VLM model: `qwen/qwen3.7-flash` (OpenRouter)
