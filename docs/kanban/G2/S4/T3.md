# G2.S4.T3: Wiki Tree Panel

## Task

Implement the Wiki tab with a navigable wiki page tree and markdown content viewer.

## Implementation

### 1. WikiView.vue (replace G1.S2 placeholder)
- Left pane: **wiki tree** using TDesign `t-tree` component
  - Data from `kb.getWikiTree()` (llm_wiki page directory structure)
  - Click to expand folders → files; click file → open content
- Right pane: **markdown content viewer**
  - Data from `kb.readWikiPage(path)`
  - Render markdown (markdown-it or TDesign-rendered), CALEO styling
  - Handle missing file / loading / error states

### 2. Wiki page routing
- Optional: deep-link to specific wiki page via query param
