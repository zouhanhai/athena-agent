# G2.S4.T1: Frontend kb API Layer + Graph Library

## Task

Build the frontend API layer for knowledge endpoints and integrate the 2D graph library.

## Implementation

### 1. web/src/api/kb.ts
- `getGraph(label?)`: GET /api/kb/graph → {nodes, edges} (from LightRAG)
- `getWikiTree()`: GET /api/kb/wiki → wiki page tree (from llm_wiki)
- `readWikiPage(path)`: GET /api/kb/wiki/page?path= → markdown
- `searchKnowledge(query)`: POST /api/kb/search → results
- Follow existing pattern: `web/src/api/chat.ts`

### 2. 2D Graph Library
- Add `v-network-graph` (Vue 3 2D network graph, SVG, pan/zoom/drag) to dependencies
- Verify it builds/loads in the Vue app
- CALEO styling hooks (orange nodes, sky-blue edges)
