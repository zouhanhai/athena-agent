# G2.S4.T2: Knowledge Graph Panel

## Task

Implement the Knowledge tab showing the 2D entity-relation knowledge graph.

## Implementation

### 1. KnowledgeView.vue (replace G1.S2 placeholder)
- Use `v-network-graph` component
- Fetch graph data from `kb.getGraph()` (LightRAG entities/edges)
- Render force-directed 2D graph
- Interactions: pan, zoom, drag nodes, click node → detail panel (entity name, type, relationships)

### 2. Data mapping
- LightRAG `/graphs` {nodes, edges} → v-network-graph {nodes, edges}
- Map node colors by entity type (CALEO palette)
- Handle empty graph (no entities yet → friendly empty state)

### 3. CALEO theme
- Node colors: orange primary #ff6633, entity types varied
- Edge: sky blue #69b3e7
- Respect dark/light theme (theme store)

### 4. Design consistency (follow existing frontend design language)
- Use **--caleo-*** CSS variables (surface/body-bg/border/text) + TDesign --td-* vars — do NOT hardcode colors
- Follow ChatView's card layout: `.knowledge-panel` (header + body) using `--caleo-surface` on `--caleo-body-bg`
- Header: `.knowledge-title` + panel consistent with `.chat-header` (title + controls)
- Empty/loading/error states styled with `--caleo-text-secondary` + surface
- Respect dark/light theme toggle (theme store, applied via :root vars)
- Match SidebarNav/navigation integration (active route highlight orange)
- Reference ChatView.vue + SidebarNav.vue + theme/index.ts for patterns
