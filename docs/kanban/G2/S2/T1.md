# G2.S2.T1: Install Rust and compile llm_wiki

## Task

Install Rust toolchain on 6900XT and compile nashsu/llm_wiki.

## Implementation

1. **Install Rust**: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y` (stable)
   - Ensure `cargo` and `rustc` in PATH
2. **Clone**: `git clone https://github.com/nashsu/llm_wiki`
3. **Compile**: build the Rust backend (cargo build --release)
   - Tauri app: may need system deps (webkit2gtk etc.) for full build; if so, build just the backend/headless parts or use available deps
4. **Verify**: llm_wiki binary produced (target/release/...)
