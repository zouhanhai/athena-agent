# G2.S2.T2: Run llm_wiki headless and verify API

## Task

Run llm_wiki headless on 6900XT and verify :19828 API works.

## Implementation

1. **Headless run**: start with Xvfb (`xvfb-run`) so Rust backend runs without GUI
   - Background (detached) to survive SSH disconnect
2. **Configure**:
   - Data directory (wiki md + index)
   - DeepSeek LLM config
   - Read Markdown from shared input-dir → generate wiki pages
3. **Verify**:
   - `curl :19828` health check responds
   - Ingest a Markdown doc → wiki page generated
   - Keyword retrieval works
   - MCP server exposes retrieval tools (confirm)
4. **Service binding**: change to 0.0.0.0 (from 127.0.0.1) for Tailscale
5. **Record port**: update Port Plan in README/spec
