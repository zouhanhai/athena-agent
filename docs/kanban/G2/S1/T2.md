# G2.S1.T2: Start LightRAG server and verify ingestion/retrieval/graph

## Task

Start the LightRAG API server on 6900XT and verify ingestion, retrieval, and graph output.

## Implementation

1. **Start server**: `lightrag-server --host 0.0.0.0 --port <port>`
   - Use a stable port (suggest 9621 or similar, avoid conflicts)
   - Run detached (background) so it survives SSH disconnect
2. **Verify ingestion**: ingest a Markdown document via API
3. **Verify retrieval**: run a semantic query, confirm results returned
4. **Verify graph**: confirm graph data available (`/graphs` endpoint or graph_visual_with_html)
5. **Health check**: confirm server responds, bound 0.0.0.0
6. **Tailscale**: confirm reachable from employee machines
