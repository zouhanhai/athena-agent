# G2.S1.T1: Install and configure LightRAG

## Task

Install LightRAG on 6900XT and configure DeepSeek + Postgres/pgvector + NetworkX.

## Implementation

1. **Install**: `pip install lightrag` (core) + `pip install lightrag[api]` (server with UI)
   - Use a dedicated Python venv (e.g. `~/lightrag-venv`) to avoid polluting system python
2. **Create config** for LightRAG:
   - `LLM`: DeepSeek (`deepseek-v4-flash` or `deepseek-chat`) as both generation + embedding
   - DeepSeek API key from `~/.pi/agent/auth.json`
   - `vector_storage`: pgvector (Postgres already running on 6900XT)
   - `kv_storage` + `doc_status`: Postgres
   - `graph_storage`: NetworkX (POC, file storage)
3. **Verify**: config dir/file exists and LightRAG imports without error
