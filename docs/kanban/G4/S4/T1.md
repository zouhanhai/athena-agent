## Context

G4.S4 makes worker progress + claim readable/reliable via an OpenCode plugin. Two sub-features:

**Auto-claim**: today the claim (status=in_progress + assignee + session_id + git push) is a manual
LLM step workers sometimes forget or do late — risking two workers claiming the same ticket. The
plugin auto-claims on the first tool call so the git push (the mutual-exclusion lock) takes effect
immediately. Reuses `claimTicket` + `GitClaimLock` from `server/src/kanban` (G3.S6.T3).

**Progress Log**: LLM workers fabricate timestamps (2026-08-09 lesson) — the plugin must stamp the
real wall-clock time at each tool execute so the last-row timestamp genuinely reflects when work last
happened. This is the stalled signal.

## Task

Build the OpenCode plugin. Key requirements:
- **Plugin residency**: global/resident, loaded at opencode serve startup from `.opencode/plugins/`.
  Distinguish workers by sessionID; parse the ticket ref from the first dispatch message
  (`GET /api/session/{id}/message` or SDK `session.messages`).
- **Auto-claim**: on first `tool.execute`, call the claim path (write status/assignee/session_id +
  git add/commit/push + kanban-index regen in ONE commit). Surface `ClaimConflictError` on a lost race.
- **Progress Log appender**: on `tool.execute.after` / `session.status`, append a row to the ticket's
  `## Progress Log` table with a real wall-clock UTC timestamp, only on a real change, rate-limited.
- Follow OpenCode's plugin API (https://opencode.ai/v2/docs/build/plugins): `tool.execute.before`,
  `tool.execute.after`, `session.*`, `message.*`, `command.*`; context has `project/directory/client/$`.

## Acceptance

- Auto-claim works (happy path + lost race → ClaimConflictError).
- Progress Log rows are appended with real timestamps, rate-limited, on real changes only.
- Plugin unit tests green.

## Notes

- Reuse `claimTicket` / `GitClaimLock` / `write-index.ts` from the existing server code — do not

- The plugin lives with the athena repo for versioning (e.g. `opencode-plugin/`) but runs inside
  opencode serve. See §18 of `gdd/docs/design.md`.
