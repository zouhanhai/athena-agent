## Context

T6 made the Project board show only the Spec card (removed the per-ticket `addIssueToProject`). The
user (2026-08-13) looked at the live GitHub board and confirmed GitHub's native behavior is that
sub-issues ALSO appear as their own cards spread across the Status columns (e.g. a Spec card with
aggregated progress + each sub-issue in its own column). This is the desired behavior — T6's "only the
Spec is a card" restriction should be reverted so the board shows sub-issues spread across columns.

   - Each ticket sub-issue is added to the Project AND synced to its Status column (existing
     `syncTicketStatus` path — restore it so sub-issue cards land in their correct columns).
   - The Spec card keeps its aggregated segmented progress bar (computed from closed sub-issues —
     already implemented in T6, keep it).
