## Context

The Issues panel (IssuesTab) loads the GitHub issues list once; after a sync adds new issues
(e.g. T11-T16 → GitHub issues #12-#17), the list is stale until a full page reload. The user (2026-08-14)
wants a **Refresh button** to re-fetch the list in place. The Kanban GitHub Project view already has a
Refresh (verified), but confirm; if it lacks one, add it so synced board changes show up too.

## Task

1. **Issues panel Refresh** (`web/src/components/IssuesTab.vue`):
   - Add a Refresh button near the list header that re-calls the issues list fetch.
   - Show a loading state while re-fetching; update the list in place (no full page reload).
   - Keep the currently-selected issue's detail open (or refetch it too).

2. **Kanban GitHub Project view** (`web/src/components/KanbanTab.vue`):
   - Confirm it has a Refresh button (the GitHub view likely does). If missing, add one so a synced
     board change shows up without reload.

3. **Tests** (`web/src/__tests__/issues-tab.spec.ts` / `kanban-tab.spec.ts`):
   - Assert clicking Refresh triggers a re-fetch and updates the list.
   - Web tests green + vue-tsc clean.
