## Context

S5 syncs md (source) to GitHub Project v2 (team discussion surface). The Workbench Kanban tab currently
shows only the local md board. This ticket adds a **view toggle** so the user can see either the local
board (rich: Progress Log, stalled, goal tree, column expand) or the **GitHub Project board** (the
synced board: status columns, cards, links to GitHub for discussion).

## Task

1. **Backend endpoint** (`server/src/routes/kanban.ts` or `github.ts`):
   - `GET /api/kanban/github-project` (or similar) — returns the synced Project items for the selected
     repo: status column → cards (title = ticket ref + title, status, issue URL). GraphQL-backed via the
     employee token; only when the repo has a linked Project.
   - `GET /api/kanban/github-issue-comments?repo=&issueNumber=` — returns the GitHub issue comments
     (via the existing GitHubApi.getIssueComments) so the local detail panel can show discussion without
     leaving the Workbench.

2. **Frontend toggle + local detail panel** (`web/src/components/KanbanTab.vue`):
   - A view toggle: **Local | GitHub Project** (TDesign tabs or segmented control).
   - **Local view**: existing board unchanged.
   - **GitHub Project view**: renders the fetched Project items as columns by Status, each card shows
     the ticket ref + title + status.
   - **Clicking a card opens a LOCAL detail panel** (a drawer/modal, NOT a GitHub redirect): shows the
     ticket details pulled from local md (description, Progress Log, frontmatter — the md is the rich
     source) PLUS the GitHub issue comments fetched via the comments endpoint. This keeps the whole
     workflow inside the Workbench — no need to jump to GitHub.
   - Keep the existing goal tree / column expand only in Local view.

3. **Tests** (`web/src/__tests__/kanban-tab.spec.ts`): mock the endpoints; assert the toggle renders,
   GitHub view shows the synced columns/cards from the mocked response, clicking a card opens the local
   detail panel (not a redirect) showing md details + mocked comments, Local view unchanged, switching
   isolated. Web tests green + vue-tsc clean.

## Acceptance

- Toggle Local | GitHub Project works.
- Local view unchanged (Progress Log, stalled, goal tree, expand).
- GitHub view shows synced board; clicking a card opens a LOCAL detail panel with md details + GitHub
  comments (no GitHub redirect).
- Web tests green, vue-tsc clean.
