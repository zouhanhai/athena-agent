## Context

S5 syncs md (source) to GitHub Project v2 (team discussion surface). The Workbench Kanban tab currently
shows only the local md board. This ticket adds a **view toggle** so the user can see either the local
board (rich: Progress Log, stalled, goal tree, column expand) or the **GitHub Project board** (the
synced board: status columns, cards, links to GitHub for discussion).

## Task

1. **Backend endpoint** (`server/src/routes/kanban.ts` or `github.ts`):
   - `GET /api/kanban/github-project` (or similar) — returns the synced Project items for the selected
     repo: status column → cards (title = ticket ref + title, status, issue URL). GraphQL-backed via the
     employee token; only when the repo has a linked Project.

2. **Frontend toggle** (`web/src/components/KanbanTab.vue`):
   - A view toggle: **Local | GitHub Project** (TDesign tabs or segmented control).
   - **Local view**: existing board unchanged.
   - **GitHub Project view**: renders the fetched Project items as columns by Status, each card shows
     the ticket ref + title + status, and links to the GitHub issue/project page for discussion.
   - Keep the existing goal tree / column expand only in Local view.

3. **Tests** (`web/src/__tests__/kanban-tab.spec.ts`): mock the new endpoint; assert the toggle renders,
   GitHub view shows the synced columns/cards from the mocked response, Local view is unchanged, and
   switching is isolated. Web tests green + vue-tsc clean.

## Acceptance

- Toggle Local | GitHub Project works.
- Local view unchanged (Progress Log, stalled, goal tree, expand).
- GitHub view shows synced board + links to GitHub discussion.
- Web tests green, vue-tsc clean.
