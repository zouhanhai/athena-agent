## Context

The ticket state machine (state-machine.ts) is `backlog → in_progress → done → in_review →
approved/rejected`. Specs currently use a loose string status (`backlog/active/in_progress/done`) with
no enforced state machine — a Spec is only moved by hand and had no review/approval stages. The user
(2026-08-13) wants Specs to have the SAME full lifecycle as tickets, triggered by a plan agent / human
reviewer (like a ticket's acceptance flow), so a Spec can be in_review → approved/rejected.

## Task

1. **Typed Spec status** (`server/src/kanban/schema.ts`):
   - Add `SPEC_STATUSES = ["backlog","in_progress","done","in_review","approved","rejected","canceled"]`
     (same set as tickets) + `export type SpecStatus`.
   - `SpecFrontmatter.status: SpecStatus` (typed), validated against SPEC_STATUSES.
   - Backward compat: treat existing `active` as `in_progress` (map `active` → `in_progress` on parse,
     or accept it as an alias) so current Specs parse.

2. **Spec state machine** (`server/src/kanban/state-machine.ts`):
   - Add a Spec state machine mirroring the ticket one: `backlog → in_progress → done → in_review →
     approved/rejected`. Reuse the same STATE_MACHINE structure (or a Spec variant).
   - `canTransition`/`transitionsFrom`/`transitionsTo`/`transitionId` work for Specs.
   - Transitions are triggered by a plan agent / human reviewer (not auto from ticket completion).

3. **status-map** (`server/src/kanban/status-map.ts`):
   - Extend `KANBAN_SPEC_STATUS_TO_PROJECT_STATUS` for the new states: `in_review → "In Review"`,
     `approved → "Approved"`, `rejected/canceled → "Rejected"` (or a sensible column).
   - `ensureStatusFieldOptions` in github-sync must add these columns to the Project board Status field.

4. **Tests**:
   - schema test: Spec status validated against SPEC_STATUSES; `active` alias accepted.
   - state-machine test: Spec transitions (backlog→in_progress→done→in_review→approved; in_review→rejected).
   - status-map test: new Spec states map to Project columns.
   - github-sync test: ensureStatusFieldOptions adds the new Spec columns.
   - Server tests green, typecheck clean.
