## Context

The detail panel's Progress Log section (`web/src/components/KanbanTab.vue` ~line 702-711) always renders
the full list expanded. The Progress Log can be long; the user wants it **collapsed by default**, clickable
to expand (2026-08-14). This is a pure frontend UX tweak in the detail panel.

## Task

1. **Collapsible Progress Log** (`web/src/components/KanbanTab.vue`):
   - Add a local `progressOpen` ref (default false).
   - The "Progress Log" title (`h5.kanban-detail-progress-title`) becomes clickable, with a ▸/▾ indicator.
   - `v-show` the list based on `progressOpen`.
   - When the detail panel opens for a card, reset `progressOpen` to false (so each open is collapsed).

2. **Tests** (`web/src/__tests__/kanban-tab.spec.ts`):
   - Assert the Progress Log list is NOT visible by default when the panel has a Progress Log.
   - Assert clicking the title makes the list visible; clicking again hides it.
   - Web tests green + vue-tsc clean.

## Acceptance

- Progress Log collapsed by default; click title to expand/collapse.
- Rest of the panel unchanged.
- Tests green, vue-tsc clean.
