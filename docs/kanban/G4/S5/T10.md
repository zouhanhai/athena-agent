## Context

On the live GitHub board, a Spec card shows `G4.S5 Kanban ↔ GitHub Issues bidirectional sync + planning
feedback loop` (title), but a ticket card shows only `G4.S5.T1` (just the ref) — the user (2026-08-13)
wants ticket cards to show a readable description too, like the Spec card. Ticket sub-issues are created
by `buildIssueForTicket`, which currently sets `title = ticketRef` (bare ref). The Spec main issue uses
`specIssueTitle` = `ref + stripped title`. Make tickets consistent: `ticketRef + stripped title`.

   - `createSpecIssue` updates existing ticket sub-issues by title (it already resolves by title via
     `getIssueByTitle`); since the title now includes the description, ensure idempotent updates still
     work (re-run sync updates the title on already-created tickets).

     `{ title: "G4.S5.T1 <ticket title>", body }`; `stripRefPrefix` strips a `G4.S5.T1:` prefix.
