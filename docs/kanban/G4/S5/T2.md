## Context

G4.S5.T1 built the GraphQL/API layer. This ticket implements the **md → GitHub projection**: turn the
local md kanban (source of truth) into the GitHub Project board — Spec main Issue (body = design doc +
discussion), Ticket sub-issues (status column, blocked_by, Goal milestone/label). md stays the single
source of truth; GitHub is the team discussion/visibility surface (multi-person projects).

## Task

1. **Projection builder** (`server/src/kanban/github-sync.ts`):
   - `buildIssueForSpec(board, specRef)` → `{ title, body, labels }` for the Spec main Issue
     (title `Gx.Sx <title>`, body = spec description + link + `## Sub-tasks` checklist of tickets).
   - `buildIssueForTicket(board, specRef, ticketRef)` → the sub-issue payload
     (title `Gx.Sy.Tz`, body = ticket Context/Task/Acceptance from the md + link to the md file).
     **Do NOT include the Progress Log** in the body — it stays in md only (avoid GitHub noise).
   - `statusToColumn(status)` → Project Status option; `blockedByToDeps(ticket.blocked_by)` →
     issue dependency numbers; `goalToMilestoneAndLabel(goalRef)` → `{milestone, label}`.

2. **Sync functions**:
   - `createSpecIssue(github, credential, owner, repo, board, specRef, project)` → creates the main
     Issue + adds it to the Project, creates the Goal milestone/label, adds each ticket as a sub-issue.
   - `syncTicketStatus(...)` → moves the sub-issue's card to the right Project Status column.
   - `syncBlockedBy(...)` → set issue dependencies.
   - Idempotent: `getIssueByTitle` first; if it exists, update in place (no duplicate).

3. **Sync CLI/tool** (`server/scripts/sync-github.ts`, board.js-style):
   - Commands: `create <specRef>` (Spec→Issues→Project), `sync <specRef>` (push ticket states),
     `status <ticketRef> <column>`, `list`. Reuse the employee GitHub credential store.

4. **Tests** (`server/test/kanban-github-sync.test.ts`): mock GitHub; assert Spec Issue body,
   Ticket sub-issue creation, status→column mapping, blocked_by dependencies, Goal milestone/label,
   idempotent re-run (no duplicate). Server tests green + typecheck clean.
