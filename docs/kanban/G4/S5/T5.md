## Context

The S4 done double-commit plugin (G4.S5.T5) has two push/timing races observed on 6900XT:

**3a — index commit not pushed on push-failure.** In `done-commit.ts` `commitDoneIndex`, when
`git push origin <branch>` fails, the catch does `fetch` + `rebase`, then loops back. After the rebase
the index often already reflects done (the remote had the worker's version), so `indexDiffers` returns
false and the function returns — **but the plugin's own `index done <ref>` commit (added at line 94-103)
was never pushed**, leaving the 6900XT repo `[ahead 1]` with an orphan index commit. Observed: T4 done,
index commit `8ee11d1` not pushed to origin.

**3b — duplicate index commit.** When a worker manually regenerates + commits the index as part of its
done commit (as T3's worker did, `b101a82`), the plugin's `session.idle` handler runs `commitDoneIndex`,
builds the index again, and — because of a timing race (the worker's index wasn't yet on HEAD when the
plugin checked) — produces a SECOND `index done` commit (`57450be`). The D29 no-op check
(`index already reflects done → no commit`) misses this race.

## Task

1. **Fix 3a** (`done-commit.ts`): after a push failure + rebase, if the local `index done <ref>` commit
   exists and is unpushed, push it (don't lose it). Restructure so the commit is either pushed or the
   rebase cleanly absorbs it — never a silent local-only commit.
2. **Fix 3b** (`done-commit.ts`): make the no-op check robust to the race where the worker's index was
   committed but not yet on the plugin's HEAD at check time — e.g. check `git diff origin/<branch>`
   after a fetch (does the index already reflect done on the remote?), or compare against the remote
   ref, so a worker-already-regenerated index produces exactly one commit.
3. **Tests** (`opencode-plugin/test/done-commit.test.ts`): add a mock test for 3a (simulate push
   failure + rebase; assert the index commit is still pushed, no `[ahead 1]`) and 3b (simulate worker
   already committed index; assert the plugin produces exactly one `index done` commit, not two).

## Acceptance
