# G4.S1.T4: pipeline integration

## Task

Wire the refinement step into the ingest pipeline (per G4.S1 Spec: Athena is the single full-doc LLM pass).

## Pipeline change

Current (tasks.ts): `parsing (docling)` → `ingesting_lightrag ‖ ingesting_llmwiki`.
New: `parsing (docling)` → **`refinement (refine_document)`** → `ingesting_lightrag ‖ ingesting_llmwiki`.

## Fold llm_wiki classify

- `llm_wiki.classify` (type+topic) is folded into refinement — Athena decides type/topic once.
- Downstream llm_wiki just writes page + frontmatter + rebuilds index (pure I/O, no LLM).

## Downstream consumption

- **llm_wiki**: writes re-leveled md + frontmatter (type/topic) → wiki dir + index.
- **RAG (G4.S2)**: receives Athena-injected chunks/entities/keywords/topic → embeds + indexes (no LLM).
- Key separation: `DOCLING_OPENROUTER_KEY` (docling VLM) vs `ATHENA` provider (refinement) vs
  `EMBEDDING_OPENROUTER_KEY` (S2 embedding) — independent.

## Progress surface

- Refinement stage status/progress on the Uploads page (like parsing/ingesting stages).

## Deliverables

- `refinement` stage in tasks.ts + coordinator.
- classify folded; downstream consumption wired.
- Uploads progress for refinement.
