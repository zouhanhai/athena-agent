# G4.S1.T2: refine_document output contract + skill + prompt

## Task

Define `refine_document`'s output contract and the `document-refinement` skill + prompt (per G4.S1 Spec,
including the cross-RAG extraction comparison).

## Output contract (JSON schema, constrainedSampling)

```jsonc
{
  "markdown": "...",                    // re-leveled markdown (header hierarchy fixed)
  "frontmatter": { "type": "...", "topic": "..." },   // from docs/taxonomy.md
  "chunks": [{ "id": "c1", "text": "...", "heading_path": "..." }],  // paragraph-semantic, ~1200 tok
  "entities": [{ "name": "...", "type": "org|person|...", "description": "..." }],
  "relations": [{ "source": "...", "target": "...", "keywords": ["..."], "description": "..." }],
  "keywords": ["..."],
  "quality": { "complete": true, "confidence": 0.85, "issues": ["..."], "action": "auto_accept|review_required" }
}
```

## `document-refinement` skill (SKILL.md)

Teaches the refinement pass:
- **Header re-level**: semantic `#`/`##`/`###` (fix flat h2, e.g. Sommerseminar 16×h2).
- **Classification**: type (CALEO types) + topic (hierarchical tree, docs/taxonomy.md).
- **Entity/relation extraction**: name title-case normalization, binary relations, only direct/meaningful
  (from the cross-RAG comparison in the Spec).
- **Quality checklist**: completeness vs source, table/figure capture, garbled text.
- **Single full-doc pass** (context-efficient).

## Prompt template

One prompt (PromptTemplate) doing re-header + classify + entity/relation/keyword + quality in one pass,
constrained by the JSON schema.

## Deliverables

- Output contract schema (TypeBox for ToolDefinition params).
- `document-refinement` SKILL.md.
- Prompt template.
