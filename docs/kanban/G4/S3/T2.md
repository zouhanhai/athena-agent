## Background

Athena is the single LLM pass. A scheduled/on-demand KB review scans each wiki page's frontmatter and
decides lifecycle actions (G4.S3 core).

## Task

1. Add an Athena KB review pass that scans wiki frontmatter (read_count / last_reviewed / confidence /
   topic_history / updated) and decides for each page:
   - re-topic → update `topic` + append to `topic_history` + bump `last_reviewed`
   - re-classify → update `type`
   - deprecate/fade → lower `confidence`; if very stale + rarely read, flag for archive
   - reinforce → a fresh confirming source raises `confidence`
2. `read_count` + `last_reviewed` tell Athena what's used vs rotting.
3. Expose as an endpoint (POST /api/kb/review) + trigger on schedule/on demand.
4. TDD: review correctly decides actions from given frontmatter; confidence decays.
5. Server tests green + typecheck clean.

## Acceptance

- Athena KB review scans frontmatter and re-topics / re-classifies / deprecates / reinforces.
