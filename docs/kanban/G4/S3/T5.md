## Background

On the Chat page, a user can upvote/downvote an answer. This feeds the KB lifecycle (G4.S3, added
2026-08-11).

## Task

1. Add a feedback control on the Chat answer (thumbs up/down).
2. Backend: store Q&A pairs `{question, answer, sources, feedback}` in a DB table (reusable, avoids
   re-RAG for the same question).
3. Upvote = reinforce → raise `confidence` of the source chunks/document.
   Downvote = fade → lower `confidence`.
4. TDD: feedback stored; confidence updated per feedback direction.
5. Server + web tests green, typecheck clean.

## Acceptance

- Chat shows thumbs up/down; Q&A pairs stored; confidence reacts to feedback.
