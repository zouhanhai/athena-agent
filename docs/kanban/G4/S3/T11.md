# G4.S3.T11 — Admin console (sidebar admin nav + management)

## Context

Today Settings is a flat page with Profile + Agents. There is no admin-specific surface, and no way in
the UI to grant permissions (e.g. the new `kb.edit` from G4.S3.T10) or generate invites — those exist
only as backend APIs (`POST /api/invitations`, `GET/POST /api/employees`, `PUT /api/employees/:email`).

Goal: a dedicated **Admin console** reachable from the sidebar, visible **only to admins**, that wraps
these existing backend capabilities into a UI: employee management, permission grants (incl. `kb.edit`),
and invite-link generation.

## Task

1. **Sidebar conditional nav** (`web/src/components/SidebarNav.vue`):
   - Make `navItems` reactive; append an **Admin** item (`/admin`) only when the signed-in employee has
     `role === "admin"` (from the auth store). Members never see it.
   - Place it near Settings.

2. **Admin page** (`web/src/views/AdminView.vue` + route `/admin`):
   - **Employees list**: table of employees (email, display_name, logo, role, permissions). From
     `GET /api/employees`.
   - **Change role**: promote/demote admin ↔ member via `PUT /api/employees/:email` (admin only).
   - **Grant/revoke `kb.edit`** (from T10): a checkbox/switch per member; backed by the same employee
     update endpoint or a dedicated permission endpoint. Server enforces admin-only.
   - **Invite generation**: an input to invite an email → `POST /api/invitations`, showing the generated
     invite link (reuses the existing invite flow/TTL). List pending invites.
   - Show only what the signed-in admin can do; hide/disable anything they can't.

3. **Routing + guard**: `/admin` route; a navigation guard (or in-page check) redirects non-admins away.

## Acceptance

- Sidebar Admin entry only for admins.
- Admin can list employees, change roles, grant/revoke `kb.edit`, generate invite links.
- Server rejects non-admin calls (RBAC); UI hides admin controls for members.
- Tests: web sidebar-conditional + admin-view (list/role/permission/invite); server permission grant if a
  new endpoint is added. Suites green + vue-tsc clean.
