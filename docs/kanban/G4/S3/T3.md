## Background

Re-curate to deeper sub-topics once a topic dir grows (e.g. `internal/events/sommerseminar`).
`isValidTopic` supports arbitrary depth; topic filtering is wiki-frontmatter driven → **no Neo4j
re-chunk/re-embed** (G4.S3 core).

## Task

1. Re-curation tool: move a wiki page to a deeper topic dir + update frontmatter `topic` +
   append old topic to `topic_history` + bump `last_reviewed`.
2. Rebuild the wiki index (llm_wiki rescan) after re-topic so the tree updates.
3. No re-chunk/re-embed in Neo4j — only the wiki frontmatter + file move change.
4. TDD: re-topic updates topic + topic_history + moves file; Neo4j data untouched.
5. Server tests green + typecheck clean.
