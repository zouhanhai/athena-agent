## Context (empirical, 2026-08-26)

While debugging why Athena answered "not in KB" for a question whose answer IS in the KB
(Group Reporting doc), we measured retrieval behavior directly against
`POST /api/kb/search` on 6900XT:

| Query | Definition chunk rank |
|---|---|
| "What is SAP Group Reporting Data Collection" | #3 (score ≈ 8.1) ✅ |
| "data collection app BTP gather financial data" | #2 ✅ |
| "SAP Group Reporting Data Collection" (bare entity) | not in top 5 ❌ |
| "Group Reporting Data Collection 是什么" (Chinese) | not in top 5 ❌ |

The definition chunk is tiny (482 chars) with a perfect heading_path
("Group Reporting / Integration / SAP Group Reporting Data Collection"), embedding
present — yet ~60 other chunks mentioning "Data Collection" incidentally outrank it
under short/Chinese queries because:

1. Per-source topK is only 5 (`retrieval.ts` fused search) — one unstable source starves
   the fusion.
2. `heading_path` does not participate in scoring — a chunk whose HEADING names the
   queried entity has no advantage over body-text mentions.
3. No exact-phrase boost — the full proper noun split into scattered tokens competes
   equally with unrelated co-occurrences.

Athena self-check on the fixed pipeline (2026-08-26 evening) confirmed the variance:
full-question retrieved definition-adjacent chunk c658 instead of c7 — still relevant,
but ranking is coin-flippy across phrasings.

## Task

1. **Heading-path weighting** in the Neo4j hybrid scorer: multiply/add a boost when
   normalized query-entity terms appear in the chunk's `heading_path` property. Keep it
   deterministic and documented (constant, not an LLM call).
2. **Exact-phrase boost**: detect quoted/multi-word sequences (>2 words) in the query;
   bonus when the sequence appears verbatim (case-insensitive, whitespace-normalized)
   in text or heading_path.
3. **topK 5 → 10** per source in `KnowledgeRetrievalService.search`; keep downstream
   fusion/judge behavior otherwise unchanged (judge already re-ranks).
4. **Fixture test**: seed/detect the real Group Reporting corpus on the dev Neo4j OR
   build a minimal synthetic fixture with one definition chunk + N incidentally-
   mentioning chunks reproducing the ratios above; assert the rank matrix.
5. Optional: log per-query score decomposition (bm25/vector/heading/phrase) behind a
   debug flag for future tuning.
