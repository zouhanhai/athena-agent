## Background

A new dedicated tab "Terms & QA" shows semantic mappings (custom synonyms) and stored Q&A pairs, with
live query against the DB and manual Q&A entry (G4.S3, added 2026-08-11).

## Task

1. **Semantic mappings**: front-end to view/add/delete company-term → canonical mapping (e.g.
   "C-Day" → "CALEO Day"). Stored in a DB table; applied at query time so a colloquial term also
   matches the canonical. Complements T1 Athena aliases (DE/EN) with user-curated mappings.
2. **Q&A pairs**: the tab lists stored Q&A pairs (from the feedback loop + manual), with **live query**
   against the DB.
3. **Manual entry**: the tab lets a user type in a Q&A pair directly (knowledge injection). The
   manual add **reuses the T5 vector-dedup** (`QaEmbeddingIndex`): before insert, vector-search the
   existing Q&A for a similar question; if one matches, the front-end shows "similar Q&A exists"
   and lets the user choose merge/overwrite/add-anyway (keep the Q&A store deduped across both the
   feedback loop and manual entry).
4. New sidebar tab "Terms & QA".
5. TDD: CRUD for semantic mappings + Q&A pairs; live query; manual add (with dedup). Web + server
   tests green, vue-tsc + typecheck clean.

## Acceptance

- "Terms & QA" tab: semantic mappings CRUD + Q&A pairs list (live DB query) + manual Q&A add
  (deduped against existing Q&A via vector similarity).
