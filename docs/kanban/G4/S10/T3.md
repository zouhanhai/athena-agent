## Context

Weekly audit (T15) already covers file/graph consistency + orphan cleanup.
This ticket extends it with the graph-wide re-link: merge late-arriving
duplicates/name-variants that incremental ingest-time LINK may have missed,
and expose the result in the Admin UI. Full but layered: deterministic pre-scan
(no LLM) → candidate pairs → LLM adjudication → applied + reported.

## Task

1. Pre-scan: query the entity index for near-duplicate pairs (embedding cosine
   ≥0.85 via vector index; name/alias normalization clusters; same-name
   different-type), producing candidate pairs keyed by canonical nameUpper.
2. Adjudicate candidates via linkCandidates() (inject the same engine), batched.
3. Apply with atomic writes; produce the weekly report {trigger:"weekly",
   merges, unmergedCandidates, newEdges, candidateCount, llmCalls} into
   auditRunsStore.
4. Admin UI: display the weekly re-link report (table/accordion) alongside the
   community-quality section.
