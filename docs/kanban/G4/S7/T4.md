## Context

The AgentIDE vision: users send commands → forwarded to the right local agent → agent works locally →
streams process + result back. This ticket wires the platform Chat panel to a selected registered agent's
API Server over Tailscale, using HTTP (command send) + SSE (real-time push). Depends on T2 (agent has
api_url registered).

## Task

1. **Agent selector in Chat panel**: pick a registered agent (from T2) to route the chat to.
2. **HTTP + SSE forwarding** (NOT WebSocket): platform forwards the user message via HTTP to the agent's
   api_url; subscribes to the agent's SSE stream; pushes `tool.started` / `tool.completed` + streamed
   result deltas into the platform Chat panel.
   - Hermes agent: `GET /api/sessions/{id}/chat/stream` (SSE).
   - OpenCode agent: `/global/event`.
3. **Reachability**: over Tailscale (T1); handle agent offline / unreachable gracefully.
4. **Stream tool progress**: `tool.started` / `tool.completed` surfaced as progress rows in the panel.
5. **Tests**: server (routing + SSE forwarding + offline handling) + web (agent selector + progress rows).

## Acceptance

- Chat panel routes to a selected registered agent over HTTP+SSE (no WebSocket).
- Tool progress streams into the panel. Agent unreachable handled. Tests green, typecheck clean, live on 6900XT.
