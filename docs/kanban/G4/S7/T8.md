## Context

athena is public at athenakb.com. The router guard (T7, DONE) redirects signed-out users to /login for
protected page routes, but the **global chat panel (GlobalChatPanel) sits in the App shell**, outside the
router — so a signed-out user can still chat with Athena. The login card is in the content area
(router-view → LoginView); the sidebar may remain. Fix: hide the chat panel (and its splitter) when not
authenticated.

## Task

1. **App.vue**: wrap `GlobalChatPanel` and the `chat-splitter` div with `v-if="auth.isAuthenticated"`
   (use the auth store). Signed-out → chat panel + splitter not rendered; the login card + sidebar remain.
2. **Verify**: signed-in users still see the chat panel unchanged.
3. **Tests**: add a web test asserting the chat panel is hidden when signed out and present when signed
   in (e.g. in app.spec.ts or layout.spec.ts). Run all web tests (must stay green, currently ~456) +
   typecheck clean.

## Acceptance

- Signed-out users cannot chat (GlobalChatPanel not rendered); login card + sidebar remain.
- Signed-in users see the chat unchanged.
- Web tests green (incl. the new signed-out/signed-in chat assertion), typecheck clean.
