## Context

S7 needs the platform (control plane) to reach every remote local agent across regions. Tailscale
provides the encrypted tunnel. Currently the platform is LAN-only (APP_BASE_URL is a LAN address); remote
agents (remote WSL) can't be reached. This ticket sets up Tailscale + remote access.

## Task

1. **Install Tailscale** on 6900XT (hh@192.168.178.30, Ubuntu 24.04) and the remote WSL host:
   - `curl -fsSL https://tailscale.com/install.sh | sh` (Linux) / WSL install
   - `tailscale up` + authenticate both into the same tailnet (login with the org account)
2. **Verify tailnet**: `tailscale status` shows both nodes; note each node's Tailscale IP/name.
3. **Configure APP_BASE_URL**: point it to a Tailscale-reachable address so invite/magic-link URLs open
   remotely (update `.env.local` / config; verify the URL opens from the remote WSL).
4. **Verify SSH over Tailscale** between 6900XT and remote WSL (if applicable) — the platform's agent
   control may use SSH.
5. **Document** the tailnet setup (nodes, IPs, how the server reaches agents) in the S7 spec or gdd docs.

## Acceptance

- Tailscale up on both machines, same tailnet, reachable by name/IP.
- APP_BASE_URL is Tailscale-reachable (not LAN-only); remote invite URLs open.
- SSH/connectivity verified between the agent hosts.
- Documented. Part of G4.S7 (prerequisite for T2/T4).
