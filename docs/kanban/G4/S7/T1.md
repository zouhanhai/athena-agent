## Context

S7's model (2026-08-15) is **reverse WebSocket** (see `docs/remote-agent-connectivity.md`): remote agents
actively connect INTO the platform, works behind NAT/CGNAT, no public IP, no admin on the agent.
**Tailscale is NOT used** (remote wts has no admin). The platform exposes ONE inbound WS endpoint that all
agents (local + remote) connect into; Cloudflare Tunnel makes it reachable from anywhere. This replaces the
earlier Tailscale (T1) plan.

## Task

1. **Platform WS server**: athena server exposes a WebSocket endpoint (e.g. `/ws/agent`) that agents
   connect INTO. (Full bidirectional + registration is T4; here establish the endpoint + a basic echo/handshake.)
2. **Cloudflare exposure**: expose the platform WS endpoint publicly so remote agents reach it from anywhere:
   - **Quick tunnel** (testing, no account): `cloudflared tunnel --url http://localhost:<ws-port>`
   - **Named tunnel** (stable, free + a domain): `cloudflared tunnel login/create/route/run`
   - Document both in the spec / setup doc.
3. **Verify remote reachability**: a machine OUTSIDE the LAN (or the remote wts) can establish a WS
   connection to the platform's public endpoint.
4. **Document**: Cloudflare config + how agents reach the platform.

## Acceptance

- athena exposes a WS endpoint agents connect INTO; reachable publicly via Cloudflare (named or quick).
- Remote WS connection verified from outside the LAN. No public IP / no admin needed on agents.
- Cloudflare config documented. Part of G4.S7 (prerequisite for T2/T4).

## Notes
