platform via the federation, so either can be controlled from the platform. T1-T4 build the pieces
(Cloudflare-exposed WS endpoint, invitation onboarding, KB-MCP, reverse-WS bidirectional); this ticket
integrates them into a working end-to-end demo and verifies all S7 acceptance criteria (reverse WebSocket,
not HTTP+SSE; see `docs/remote-agent-connectivity.md`).
