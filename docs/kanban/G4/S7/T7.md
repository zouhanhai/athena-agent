## Context

athena is public at athenakb.com (Cloudflare Tunnel). Currently only /admin requires auth; all other
pages (knowledge/wiki/workbench/etc.) load without login. For a public site, every page except
login/register/verify must require a logged-in session; signed-out visitors land on /login and return
after signing in. A global auth guard was added (commit af38c4e) but the navigation tests that visit
protected pages need authentication to pass.

## Task

1. **Router guard**: in `web/src/router/index.ts`, redirect any non-login/register/verify page to
   `/login` when `!auth.isAuthenticated` (with `redirect` query back to the original path). Keep
   login/register/verify public and /admin admin-only. (Guard logic largely exists — verify + finish it.)
2. **Auth check**: `isAuthenticated` is based on the persisted session token (already in the store).
3. **Tests**: navigation tests (layout.spec, uploads-view.spec, etc.) mount protected pages — make them
   authenticated so the guard passes them through. E.g. a vitest setup that seeds a session token before
   each test, or per-test auth. Ensure signed-out tests (auth-views/register) still exercise the
   redirect correctly.
4. **Verify**: all web tests green (currently 30 fail due to the guard), typecheck clean.

## Acceptance

- Signed-out users are redirected to /login from any protected page; can return after login.
- login/register/verify public; /admin admin-only.
- All web tests green (navigation tests authenticated; signed-out tests still pass), typecheck clean.
