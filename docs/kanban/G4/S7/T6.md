## Context

athena is public at athenakb.com (Cloudflare Tunnel). The current /login page is **magic-link only**
(email → link → verify), which depends on email delivery. For a simpler public sign-in not dependent on
email, add **email + password**: users register with a password and sign in with email+password. The
current login page (see screenshot: "Sign in to Athena / Enter your work email and we'll send you a magic
sign-in link / Email / Send magic link") is plain and should be **polished to a professional look**
consistent with the athena brand (orange #ff6633 + dark slate #2d3142). Magic-link stays as a fallback.

## Task

1. **DB schema**: add `password_hash` column to `employees` (nullable; existing users have none). Migration.
2. **Backend**:
   - `POST /api/auth/login` accepts `{email, password}` → verify bcrypt (if password_hash exists); else
     fall back to magic link. Return the same session/verification shape.
   - Registration/invitation flow lets a user set a password (store bcrypt hash).
   - Add a password-set endpoint if needed (register / accept-invite).
3. **bcrypt**: add dependency + hashing/verification helper.
4. **Frontend**:
   - `LoginView.vue`: polish to a professional email+password sign-in form (brand palette); keep
     magic-link as an option. Remove/replace the plain "Send magic link" page.
   - `RegisterView.vue`: let the user set a password on registration.
   - **Guard the Chat panel too**: in `App.vue`, hide `GlobalChatPanel` when `!auth.isAuthenticated`
     (the router guard only covers page routes; the global chat panel sits in the App shell and is
     reachable even signed out). The sidebar may remain; the chat must be hidden for signed-out users.
5. **Tests**: server (login with password, wrong password rejected, magic-link still works) + web
   (password form, submit, login page renders, chat panel hidden when signed out).

## Acceptance

- Password stored as bcrypt hash, never plaintext. Wrong password rejected. Magic-link still works.
- The /login page looks polished (brand-consistent), not the plain magic-link page.
- Tests green, typecheck clean, live on 6900XT.
