## Context (2026-08-21, user requirement after T8/T9)

T8 wired local dependency edges into the graph (CDS `READS_FROM`/`ASSOCIATES`,
ABAP `CALLS`/`READS_FROM`, UI5 `BINDS_TO`); T9 adds `REFERENCES` between tables.
The data for an SE80-style cross-object browser — including the WHERE-USED list —
is therefore already in Neo4j; nothing new needs to be extracted at intake time.

User intent (verbatim): “abap unit 导航是类似 HANA Studio 还是 SE80 那种？” → T11 delivers
the ADT-Outline experience WITHIN a page; THIS ticket delivers the SE80 Repository-Browser
experience ACROSS objects: pick any class/FM/table/view, see everything it uses and
everything that uses it, click through to the wiki page containing the code.

## Design

### 1. Graph query service + routes (server)

Extend the KB read side with a small graph-query module (follow the existing Neo4j access
patterns in `store/ingest.ts`; read-only session):

- `listEntities({ type?, q?, limit? })` → `MATCH (e:Entity)` + optional type equality +
  `toUpper(e.name) CONTAINS toUpper($q)` + `ORDER BY e.name LIMIT $limit`.
- `getEntity(name)` → the entity + two directed edge lists via
  `MATCH (a:Entity {nameUpper: $n})-[r]->(b)` (outgoing = "uses") and
  `(a)<-[r]-(b)` (incoming = "used by"), carrying `type(r)`/keywords/description.
- Wiki-page resolution per related endpoint: from the endpoint entity follow
  `MENTIONED_IN` to Chunks, take distinct Chunk ids → documentId → the document's
  `wikiPath` (stored on the Document node at ingest) → link target(s).
- Routes under `/api/kb/graph/*`, employee auth, added alongside the other KB GET routes.

### 2. Browser view (web)

New lazy-loaded route (nav entry beside Wiki, e.g. "Code Browser"):

- Left: type-grouped list (collapsible per type) + search box (debounced, hits
  `listEntities`). Selecting loads the detail pane.
- Right: header (name/type/description) + two sections: `Uses` and `Used by`;
  each row shows the relation keyword and the counterpart name, linked when a wiki
  page resolved (router-push to WikiView path); unlinked rows render plain.
- Neo4j-unconfigured → explicit empty-state card. Loading/error states required.

### 3. Entity type normalization

T8 emitters use lowercase kinds (`cds_view`, `table`, `abap_unit`, `ui5_component`,
`odata_service`) while T9's DDIC store emits `Table`. Align on ONE convention (prefer the
lowercase set used by T8 — change `store/ddic.ts` accordingly) and update affected tests.
If previously-stored rows matter, note in the PR that re-ingestion refreshes them
(no online migration required for dev data).

### 4. Tests

Server: seed the test Neo4j fixture with two classes calling one FM plus a CDS reading a
table; assert `listEntities` filtering, both directions of `getEntity`, and wiki-page
link resolution. Web: vitest for list grouping/search/detail rendering/links + empty state.
