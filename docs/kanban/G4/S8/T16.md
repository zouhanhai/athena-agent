## Context (2026-08-21, first real ingest test + research report)

First real ingest through the pipeline exposed five failures sharing ONE root cause:
**no validate → feedback → report closed loop**. Full analysis:
`/home/hai/athena-refine-refactor-report.md` (read it — Part A has every file:line).

| Failure | Root cause (file:line) |
| --- | --- |
| Flat headers never re-leveled | applyPatches silently ignores misnumbered/unemitted patches (refine-output.ts:491-494); zero instrumentation |
| 64 fragmented chunks (avg 137 chars, min 3) | splitParagraphSemantic merges nothing (refine-output.ts:518-538) |
| Entities [] but 4 relations (Lüsen) | normalizeRefinementDelta has NO cross-field validation (refine-document.ts:659-697) |
| Relations silently dropped (Mallorca: nameUpper mismatches) | store/ingest.ts:329-337 exact-MATCH drops; :342-346 reports INPUT count as stored |
| Small-image caption noise | stripImageRefs keeps `<!-- image -->` placeholders (refine-output.ts:164-172) so the model sees and reports them |

Industry practice (research Part B): structured-output standard = schema constraint (shape
only) → application-side cross-field validation → feed concrete errors back for a bounded
retry → deterministic fallback. Graph extraction standard = closed-world (endpoints must
reference declared entities) and NEVER silently drop — repair or record. Contextual
enrichment (Anthropic) cuts retrieval failure 35-49% and our refine pass already reads the
full document, so per-chunk context sentences are free.

## Design

### 1. Delta validation + repair loop (refine-document.ts)

New `validateRefineDelta(delta, sourceMarkdown)` returning a list of concrete errors:

- relation endpoints must equal (whitespace-normalized) emitted entity names
- entities non-empty when relations exist
- anchor quotes present in the rebuilt markdown (T17 contract)
- frontmatter type/topic valid per taxonomy

Flow: LLM pass → validate → if errors, re-invoke ONCE PER ERROR LIST (max 2 retries)
with the errors appended to the prompt ("your previous output violated: …fix these") →
exhausted ⇒ fallbackRefinement. All retries logged (`attempt`, `errors[]`).

### 2. Neo4j consistency layer (store/ingest.ts)

- Before writing RELATION edges: resolve endpoints; missing ones are MERGE-created as
  Entities (name/nameUpper normalized; type from relation keywords heuristic or
  'unknown'; description from the relation description).
- Counters become truthful: `{relationsInput, relationsStored, endpointEntitiesCreated}`.
- Keep the T14 cascade semantics intact (orphan cleanup runs AFTER these creates).

### 3. Header apply: instrumentation + robustness

- Patch-cycle logging: `{patchesEmitted, patchesApplied, patchesDropped:[{index,reason}]}`.
- Repro test: Mallorca-shaped input (flat 16 × h2) must produce hierarchical output.
- Fix ladder: strengthen prompt examples → if ordinal indexing still misapplies, switch
  heading ops to heading-text anchoring (match by heading text) — text anchors survive
  block-count drift, ordinals do not.
- Deterministic recovery: >3 flat same-level headings + zero applied patches ⇒ run the
  batched HEADER_RELEVEL stage (already exists, refineLargeDocument) as fallback.

### 4. Minimum-size merge (splitParagraphSemantic)

Merge consecutive non-heading blocks sharing the heading path until
`>= REFINE_MIN_CHUNK_CHARS` (default 400, env `REFINE_MIN_CHUNK_CHARS`). Oversized blocks
stay intact; final block exempt.

### 5. Placeholder stripping + noise guidance

- `stripImageRefs` additionally removes `<!-- image ... -->` HTML comments.
- Refine prompt gains: below-threshold images (logos/emojis) are intentionally
  undescribed — never list them as caption issues.

### 6. Contextual enrichment (zero extra LLM calls)

Extend the single-pass output contract with `context` per chunk: one sentence combining
the document summary + section meaning ("CALEO 2023 Mallorca 研讨会日程；本段描述周四抵达
与接送安排"). Stored as `chunk.context` in chunks.json AND as a property on the Chunk node;
the RAG embed path prepends `context` to the embedded text (retrieval quality lever,
Anthropic-validated).

### 7. Unified reasoning strategy (scope addition A, 2026-08-22)

Policy by TASK CLASS, not by transport accident (before: upload path hardcoded
OpenRouter effort none; wiki-edit ran Pi `reasoning:max`). New module
`server/src/agents/refine-reasoning.ts`: `refineReasoningFor(task)` —
- "extraction" (delta emit / patches / entities / relations / header judge /
  wiki-edit re-derivation): default effort **none** (env REFINE_REASONING_EXTRACTION);
  quality guarded by the T16 repair loop instead of thinking tokens.
- "analysis" (global merge: file-level + section summaries, final quality view):
  default effort **high** (env REFINE_REASONING_ANALYSIS).
Both transports derive from this ONE function: direct callers send
`policy.effort` as OpenRouter `reasoning.effort`; Pi-runtime callers would send
`policy.piThinkingLevel`. Tests assert both paths receive the same policy values.

### 8. Provider exclusion on the direct path (scope addition B)

`callOpenRouter` body gains `provider.ignore`, value from env
ATHENA_REFINE_PROVIDER_IGNORE (comma-separated; default `["Alibaba"]`,
`resolveRefineProviderIgnore()`). Verified in production:
`~deepseek/deepseek-v4-flash-latest` (the `~` prefix is REQUIRED) + ignore
Alibaba routes stably to Relace. Test asserts the request body.

### 9. Wiki-edit refine migrated to the direct transport (scope addition C)

`runWikiEditRefine` no longer takes a Pi ModelRuntime/model — it uses the SAME
direct-OpenRouter caller as the upload path (emit contract unchanged), gaining
unified reasoning, hard timeout + retry/backoff and provider.ignore.
`createAthenaWikiEditRefiner` (kb/refiner.ts) dropped its lazy
`runtimePromise`/ModelRuntime entirely — NO Pi runtime is created anywhere in
refinement anymore.

### 10. Ingest-dedicated key chain (scope addition D)

`readAthenaOpenRouterKey` resolves in three levels:
env ATHENA_OPENROUTER_KEY → auth.json["athenaingest"] (dedicated INGEST key) →
auth.json["athena"] (chat fallback). Tests cover all three levels.
