## Context (2026-08-21, user-reported after first post-T15 ingest test)

First real ingest through the new pipeline exposed three quality defects plus a missing
data contract for the review UX (T17 depends on this ticket's structured issues):

1. **Header re-level never lands** (verified on Sommerseminar-Mallorca): the refined
   output has 16 × `##` and ZERO `#`/`###` — despite the contract requiring exactly one
   h1 title. The single-pass contract asks the LLM for `refactor_heading {index, level}`
   patches located by GRID POSITION (headings AND paragraphs counted together).
   Suspected failure: the model emits no/insufficient patches, or ordinal-position
   patching misapplies them. There is currently NO logging of patches emitted vs applied,
   so this is undiagnosable post-hoc — instrumentation is part of the fix.
2. **Chunk fragmentation** (verified): Mallorca refined md = 10,794 chars → 64 chunks,
   avg 137 chars, shortest 3 chars ("WER"). Cause: `splitParagraphSemantic`
   (server/src/agents/refine-output.ts L511) makes every paragraph block its own chunk
   and only preserves oversized blocks — there is NO minimum-size merging. Schedule-type
   documents (many one-line paragraphs) fragment badly.
3. **Small-image noise** (user-confirmed by-design): docling's picture_area_threshold
   (0.05) intentionally leaves logo/emoji-scale images without VLM captions, yet the
   refine quality report raised "3 images included, but no captions provided". Also
   VERIFY File B image-ref stripping completeness on this path — the refine LLM should
   not see image refs at all (they degrade deepseek constrained sampling).

## Design

### 1. Header apply: instrument → reproduce → fix

- Add counters/logs around the patch cycle: `{ patchesEmitted, patchesApplied,
  patchesDropped: [{ index, reason }] }` logged once per refine run.
- Repro test from the Mallorca shape (flat N × h2, short bodies) asserting hierarchical
  output. Drive the root cause to ground:
  - If the model emits wrong indices → strengthen the contract OR switch heading ops to
    **heading-text anchoring** (locate target heading by its text — ordinals are fragile,
    text anchors are not).
  - If the model emits nothing → add a deterministic fallback: when input has > 3 flat
    same-level headings and zero patches arrive, run the existing batched
    HEADER_RELEVEL_SYSTEM_PROMPT stage (stage-1 from refineLargeDocument) as recovery.
- Whichever fix lands, keep the patch contract shape for compatibility and cover it with tests.

### 2. Minimum-size merge (splitParagraphSemantic)

- After block parsing, merge consecutive non-heading blocks sharing the same heading path:
  accumulate until `>= REFINE_MIN_CHUNK_CHARS` (default 400; env
  `REFINE_MIN_CHUNK_CHARS`), then flush as one chunk. Final block may stay below minimum.
- Oversized single blocks remain intact (unchanged behavior). Merged chunk text joins
  with `\n\n`; heading_path identical across the merged set.

### 3. Structured anchored issues

- Contract upgrade: `quality.issues: string[]` →
  `quality.issues: Array<{ id, message, anchor?: { quote, headingPath }, resolved?: boolean }>`.
  The refine prompt requires the LLM to QUOTE the exact excerpt it flags.
- Athena validates each anchor quote against the rebuilt markdown
  (whitespace-normalized substring match); hits record the block index, misses set
  `anchor.resolved = false` (issue stays visible in lists, just not inline-highlightable).
- Persistence: `quality.json` (next to chunks.json) carries the full issues array; the
  wiki page frontmatter gains `review: required` (+ `review_count`). T14's cascade already
  removes quality.json with the refinement dir.
- Backward compat: old string-form issues are accepted and wrapped as `{ message }`.

### 4. Small-image noise

- First verify File B stripping completeness for this ingest path (image-ref lines must
  be absent from the refine input). Then add contract guidance: below-threshold images
  (logos, emojis — intentionally undescribed per docling picture_area_threshold) MUST NOT
  be reported as caption issues.
