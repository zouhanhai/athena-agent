1. **Git claim-lock (FIRST)**: set `status: in_progress`, `assignee: opencode`,
   `session_id: <your session id>` in the frontmatter, then commit + push. Claim lock.
2. **Context**: read this ticket + `docs/kanban/G4/S8/Spec.md` + T19 + the code list below.
   Use `codegraph explore "wiki edit refine"` / `codegraph explore "Neo4j overwrite"`.
3. **The canonical edit flow to audit (user-confirmed 2026-08-23)**:
   ```
   [pre] Neo4j already holds chunks/entities/relations from the original ingest.
   1. User edits a wiki page (fixes a few words / sections) -> save.
   2. Run refiner (wiki-edit refine, DELTA mode): markdown = edited page, before/diff/structural.
      /* RefineDocument.ts: WIKI_EDIT_REFINE_SCHEMA, WIKI_EDIT_REFINE_SYSTEM_PROMPT,
         runWikiEditRefine, extractWikiEditRefinement, normalizeWikiEditRefinement */
   3. Refiner output is an EXTRACTION delta: new_entities/new_relations (the correction's NEW
      facts) + the edit locations are given only via diff; no full markdown, no chunks.
      /* refiner.ts: createAthenaWikiEditRefiner — pins markdown from input.markdown,
         backstops chunks via readWikiEditPriorChunks + alignChunksToMarkdown */
   4. Audit pass: independent LLM session normalizes entity names / closes relation
      endpoints (auditWikiEditDocument / runEntityAudit), adoption rule = only when
      validateRefineDelta passes; never worse than pre-audit.
   5. Neo4j overwrite(input.ref, wikiPath, documentId):
      a. MERGE Document (keep md_ref), rebridge WikiPage.
      b. delete old Chunks not in new chunk-id set; re-write Sections.
      c. embed changed chunks only (unchanged chunk = same id+text+context+existing embedding).
      d. MERGE entities; writeRelations (consistency MERGE-created endpoints);
         mentionPairs -> rebuilt MENTIONED_IN edges from new chunks.
      e. stale graph cleanup: DELETE relations between entities no longer mentioned ANYWHERE
         (cross-document safe: `NOT (a)-[:MENTIONED_IN]->(:Chunk)` checks the whole graph),
         DELETE fully orphaned Entity nodes.
      /* kb/store/ingest.ts overwrite() */
   [post] New entities/relations are in the graph, removed ones are cleaned,
   the changed sections' chunks carry the new text + fresh embeddings, all in one edit save.
   ```
   - Audit step-by-step. For each step produce implement / partial / missing + evidence.
4. **Write the tests above (items ①-⑤) using `tdd` FIRST, then fix only what breaks
   the flow (crash/data-loss/wrong graph). For gaps that are enhancements, write the
   gap report in the ticket; do not implement them unless they'd break the flow.**
