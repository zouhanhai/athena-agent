## Context

Three live edit-round bugs (2026-08-23) drove this audit:
1. **0-chunks wipe**: after the delta-mode rollout, the wiki-edit LLM no longer emits chunks; an empty chunk set made Neo4j overwrite() delete every old chunk (log said "0 chunks re-embedded", Lüsen lost its 6 chunks).
2. **Missed re-embed**: with chunks gone/mechanical, a few corrected words either re-embedded nothing or everything — never exactly the changed section.
3. **Dedup zombie**: after a server restart, ContentDedupStore.ensureSeeded registered pages under their FULL wiki path while deleteDocument purged only bare basenames — re-upload was instantly marked duplicate.

Fixes shipped: delta schema/prompt/normalize (22cba64), mechanical chunk backstop (4f56a6c),
alignChunksToMarkdown (1d127a2), three-key dedup purge + script cleanup (9bb1492).
The user defined the canonical edit flow (below) and wants it audited step-by-step against
these changes, with tests so the flow cannot regress again.

## Task

Audit this CANONICAL edit flow (user-confirmed 2026-08-23) against the code:

```
[pre] Neo4j holds chunks/entities/relations from the original ingest
1. User edits a wiki page (few words / sections) -> save (PUT /api/kb/wiki/page).
2. Run refiner — wiki-edit refine, DELTA mode: markdown=edited page, before/diff/structural.
   (server/src/agents/refine-document.ts: WIKI_EDIT_REFINE_SCHEMA, WIKI_EDIT_REFINE_SYSTEM_PROMPT,
    runWikiEditRefine, extractWikiEditRefinement, normalizeWikiEditRefinement)
3. Refiner output is an EXTRACTION delta: new_entities/new_relations (correction's NEW facts);
   edit locations come only via diff; no full markdown, no chunks.
   (server/src/kb/refiner.ts: markdown pinned from input.markdown; chunk backstop via
    readWikiEditPriorChunks + alignChunksToMarkdown)
4. Audit pass: independent LLM normalizes names / closes endpoints
   (refine-document.ts: auditWikiEditDocument / runEntityAudit); adopt only if validateRefineDelta passes.
5. Neo4j overwrite(input.ref, wikiPath, documentId):
   a. MERGE Document (keep md_ref), rebridge WikiPage.
   b. DELETE old chunks not in new chunk-id set; rewrite Sections.
   c. EMBED changed chunks only (same id+text+context+existing embedding => unchanged).
   d. MERGE entities; writeRelations (consistency-created endpoints);
      mentionPairs -> rebuilt MENTIONED_IN edges from the new chunks.
   e. STALE cleanup: DELETE relations between entities no longer mentioned ANYWHERE
      (cross-document safe: `NOT (a)-[:MENTIONED_IN]->(:Chunk)` checks the whole graph),
      DELETE fully orphaned Entity nodes.
   (server/src/kb/store/ingest.ts: overwrite())
[post] New entities/relations in graph; removed entities cleaned; changed sections'
chunks carry new text + fresh embeddings; one edit save does all of it.
```

For each step produce: implemented / partial / missing + file:line evidence.
