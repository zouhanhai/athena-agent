## Task

Implement retrieval over the Neo4j store with neo4j-graphrag: HybridRetriever (vector+full-text fusion),
BM25 (FULLTEXT index), Text2Cypher, ToolsRetriever to fuse wiki + topic + vector + graph. Replace the
LightRAG path in `KnowledgeRetrievalService.search` while keeping the llm_wiki keyword source.

## Steps

- Build retrieval: HybridRetriever (vector + BM25 over chunks) + graph traversal (Text2Cypher).
- Topic filter (topic from frontmatter) to converge document domain.
- Keep llm_wiki BM25 source fused via Promise.allSettled (mirror current search).
- ToolsRetriever lets the LLM pick the best retriever per query.
- TDD: retrieval tests (vector hit, BM25 hit, topic filter, graph traversal).

## Acceptance

- Retrieval returns fused results (vector + BM25 + graph + topic); case-insensitive.
