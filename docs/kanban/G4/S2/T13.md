## Background

Athena is the single full-document LLM pass in the ingest pipeline. It already reads the whole text,
so emitting a concise document summary costs nothing extra (unlike a separate summary LLM call).
This summary feeds a hierarchical/content index for retrieval (docs/ingest-retrieval-flow.md):
a user can search summaries to locate the most relevant document before digging into its chunks.

## Task

1. **Contract** (refine-document.ts): `RefinedDocument` + `RefinementOutputRef` gain a `summary`
   field (string, ~2-3 sentences). Update `REFINED_DOCUMENT_SCHEMA`, prompt, `normalizeRefinedDocument`.
2. **Neo4j** (store/ingest.ts): store `summary` on the `Document` node.
3. **llm_wiki** (ingest.ts / llmwiki): write summary to the wiki page frontmatter (e.g. `summary:`).
4. **Retrieval** (optional, if easy): a summary fulltext index so summary text is searchable.
5. **TDD**: refine emits summary; summary persisted to Document + wiki frontmatter.
6. Server tests green + typecheck clean.
