## Task

Validate Neo4j 2026 Community in Docker on 6900XT before committing to self-build. Confirm it meets
the retrieval needs: vector index, Cypher SEARCH, in-index filters, case-insensitive lookup.

## Steps

- Run Neo4j 2026 Community in Docker on 6900XT (ports + auth).
- Verify `CREATE VECTOR INDEX` (HNSW, cosine) on a test `Chunk` node set.
- Verify Cypher `SEARCH` clause + `SEARCH…WHERE` (in-index filters by topic).
- Verify case-insensitive node lookup (toCUpper / toLower on indexed props).
- Write a decision record in `docs/adr/` (self-build vs keep LightRAG) with the spike results.

## Acceptance

- Neo4j runs; vector + SEARCH + filter + case-insensitive verified with a tiny dataset.
- ADR records the decision (self-build confirmed or not).
