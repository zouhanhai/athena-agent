## Task

Define and implement the Neo4j schema for the single lean store: `Chunk` (embedding + topic + text,
Athena-provided), `Entity`/`Relation` graph (Athena-provided, with `aliases[]` from T1), `Document`/
`WikiPage`. One store for vector + graph + topic.

## Steps

- Schema module (Cypher for node/relation labels + properties + constraints + indexes).
- `Chunk`: {id, text, embedding, topic, heading_path}.
- `Entity`: {name (canonical), aliases[], type, description}. `Relation`: {source, target, keywords[],
  description}.
- `Document`: {id, topic, type, md_ref, title}.
- Case-insensitive-friendly indexing (folded name/alias).
- TDD: schema tests (constraints + indexes applied).

## Acceptance

- Neo4j schema module creates nodes/relations/indexes; folded (case-insensitive) name/alias indexed.
