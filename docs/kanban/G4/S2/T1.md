## Task

G4.S1's `RefinementEntity` has only `name/type/description` (single-language). S2's RAG must find one
entity node in BOTH German and English — a user searching German ("Zentraler Omnibusbahnhof") must match
the EN node (ZOB München), and vice versa. Extend the S1 refinement contract to emit bilingual aliases.

## Observed (S1 test, Infos_Sommerseminar_2026.pdf)

Athena produced 14 entities like `{name: "ZOB München", type: "location", description: "..."}` — no
aliases. Keywords were mixed DE/EN but entities were single-language. RefinementEntity = {name, type,
description}.
