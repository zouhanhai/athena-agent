## Observed (2026-08-10)

`refine_document` occasionally returns "output does not match the refinement contract
(markdown/frontmatter/quality)" — the LLM drops one of the required top-level fields on some calls
(deepseek-v4-flash structured-output variability). Current default is `retries ?? 1` (refine-document.ts
`runRefinePass`), i.e. at most 2 attempts before falling back to raw docling. On the Infos re-upload the
LLM failed on the first call and the single retry also failed → fell back (entities/chunks empty), even
though 3 manual calls all succeeded.

## Task

- Raise the **default `retries` from 1 → 3** (so up to 4 attempts) in `runRefinePass`
  (`refine-document.ts`).
- Keep the existing retry test (`retries once before giving up` → assert it now retries up to the new
  default; assert `details.retries` reflects the new default).
- Confirm a spurious-failure fallback is rare: the existing image-heavy test still passes; a manual
  `createAthenaRefiner` on the Infos doc should succeed.
- Server tests green + typecheck clean.
