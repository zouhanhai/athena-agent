## Context

GDD (git-driven development) is a **generic, agent-agnostic dev-flow protocol** that runs on the
**user's LOCAL machine** — the user's own plan agent (Eng Director) and code agent (Worker) operate on
`docs/kanban/*.md`, sync them to GitHub, and log Progress Log. athena is only an OPTIONAL viewer.
T3 separates GDD into an independently-runnable `gdd/` package (local-token credential). This ticket
writes the `docs/gdd/` **handbook** that documents the separated GDD so any team can adopt it on their
own repo without athena coupling.

## Task

2. **Write** `docs/gdd/setup.md` — step-by-step enable GDD on a NEW project: copy GST templates, install
