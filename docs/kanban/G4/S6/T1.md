## Context

The Workbench currently has Code / Issues / Kanban sub-tabs. The **Kanban sub-tab mixes two unrelated
things** (2026-08-14 decision):
- **Local GST board** (reads `docs/kanban/Gx/Sx/Tx.md` + `kanban-index.json`) — this is part of
  **GDD** (git-driven-development), tied to the Gx.Sx.Tx structure.
- **GitHub Project view** (reads the repo's linked Project v2 board) — this is a **generic athena
  capability** (anyone can view a GitHub Project, GDD not required; e.g. abaplorer users view GitHub
  issue/project in Workbench but never use the GDD kanban).

They should be **two sibling sub-tabs under the Workbench** (not separate top-level pages) so the GDD
board and the athena GitHub viewer don't conflate:
- **Kanban sub-tab** → only the local GST board (GDD).
- **Project sub-tab** (new, 4th) → the GitHub Project view + issue detail panel + comment thread +
  project selector (moved out of KanbanTab).

## Task

1. **Split the view** (`web/src/components/KanbanTab.vue` → two components):
   - Keep the local GST board in `KanbanTab.vue` (remove the `view` switch + GitHub-view code).
   - Move the GitHub Project view (project selector, board cards, card detail panel with GitHub issue
     body + comments, comment input) into a new `ProjectTab.vue` (or `GithubProjectTab.vue`).
   - Preserve `@open-issue` emit on both so `handleOpenIssue` in WorkbenchView still switches to the
     Issues tab and locates the issue (G4.S5.T8).

2. **Workbench tabs** (`web/src/views/WorkbenchView.vue`):
   - Add a `Project` tab (value e.g. `"project"`) next to Code/Issues/Kanban.
   - `Kanban` tab renders `KanbanTab` (local GST only). `Project` tab renders `ProjectTab`.
   - Keep the same shared `selectedRepo` and layout styling (`.tab-panel-*` classes).

3. **Tests**:
   - Update `web/src/__tests__/` for the new component split (KanbanTab local-only, new ProjectTab).
   - Verify a Project card still opens the local detail panel (no GitHub redirect) + 'view in Issues'
     still works.
   - Server + web tests green, typecheck/vue-tsc clean.

## Acceptance

- Separate Project tab; Kanban tab shows only the local GST board.
- GitHub Project view behaves identically to today, just in its own tab.
- 'view in Issues' preserved. Tests green, vue-tsc clean, live-verified on 6900XT.
