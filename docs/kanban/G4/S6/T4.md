## Context

Decision (2026-08-14): the **local Kanban tab is redundant** — the **GitHub Project panel**
(ProjectTab.vue, from T1's split) shows the same GDD board (spec cards + sub-issues + progress +
status) and is collaborative/generic (anyone can use a GitHub Project). Removing the local Kanban tab
makes GDD separation clean: **GDD = md (source of truth) + md↔GitHub sync + Progress Log/stalled
(md-level mechanism)**, with **no athena local-board display layer** (no kanban-index/scan needed).

Progress Log / stalled are NOT affected: the worker plugin still writes the Progress Log to the md
ticket, and the local plan agent (Eng Director) still reads the md Progress Log directly to detect
stalled workers. Only the front-end board display (KanbanTab + its local board stack) is removed.

## Task

1. **Frontend**:
   - Remove `web/src/components/KanbanTab.vue` and the Kanban sub-tab from `web/src/views/WorkbenchView.vue`
     (tabs become Code / Issues / Project). Keep `ProjectTab.vue` (GitHub Project view) as the only
     board view; behavior identical.
   - Remove the local-board API calls from `web/src/api/kanban.ts` (the `/api/kanban` local board); keep
     the github-project/github-issue calls used by ProjectTab.
   - Update tests: `web/src/__tests__/kanban-tab.spec.ts` (remove or repurpose), `workbench-shared-repo.spec.ts`.

2. **Backend**:
   - Remove the local-board stack: `server/src/kanban/scan.ts` (local scanBoard; keep only what
     github-sync needs — or remove scan entirely if unused), `index-file.ts`, `write-index.ts`,
     `kanban-index.json`, and the local-board part of `server/src/routes/kanban.ts` (`GET /api/kanban`,
     scanRemoteBoard, toIndex/readRemoteIndex).
   - KEEP: `github-sync.ts`, `github-feedback.ts`, the `GET /api/kanban/github-project` route, md↔GitHub
     sync CLI (`sync-github.ts`), git hook, opencode plugins, `docs/kanban/*.md` + templates.

3. **GDD handbook** (note for T3): Progress Log + stalled are GDD-protocol mechanisms (md-level), not a
   frontend feature — document this.

## Acceptance

- Kanban sub-tab + KanbanTab.vue removed; Project is the only board view.
- Local board stack (kanban-index/scan/write-index/index-file + /api/kanban) removed.
- GDD md + sync + Progress Log/stalled kept. Tests green, vue-tsc clean, live-verified on 6900XT.
