### 2026-08-08 — opencode (ses_9a4b7c2d5e1f8a3b) — done

GitHub-style **Code tab** for the Workbench: repo tree + branch selector (left), code view with line numbers + per-language syntax highlighting (right), all scoped to the per-user credential. The S6.T5 API only covered repos/tree/PR/Issue, so the backend was extended with branches + file content (still scoped to the per-user credential).

**Server — S6 GitHub API extension (TDD, `github-client.test.ts` / `github-routes.test.ts`)**
- `server/src/github/client.ts`: `GithubBranch` + `GithubFileContent` types; `listBranches` (GET `/repos/{o}/{r}/branches`) and `getFileContent` (GET `/repos/{o}/{r}/contents/{path}?ref=`, base64 → UTF-8) on `GitHubApi` + `GithubRestClient`.
- `server/src/routes/github.ts`: `GET /api/github/repos/:owner/:repo/branches` and `GET /api/github/repos/:owner/:repo/content?path=…&ref=…` — both go through the existing `withCredential` helper, so they are scoped to the signed-in employee's credential only (401 no auth / 400 no credential / 400 missing params covered).

**Frontend**
- `web/src/api/github.ts` — `fetchRepos` / `fetchBranches` / `fetchTree` / `fetchFileContent`, every call Bearer-scoped to the session token.
- `web/src/github/tree.ts` — `buildTree`: flat recursive git tree → nested folders/files (folders first, alphabetical; implicit dirs; submodule leaves).
- `web/src/github/highlight.ts` — lightweight per-language tokenizer (19 languages by extension via `detectLanguage`) + `renderCodeLines` (per-line escaped HTML with token spans; multi-line comments/strings colored on every line). All source text is HTML-escaped before emitting → safe for `v-html`.
- `web/src/components/CodeTab.vue` + recursive `CodeTreeNode.vue` — repo select → branches + tree load (default branch), expandable folders, file click → line-numbered, syntax-highlighted view; empty state without a session; error banner on API failure.
- `web/src/views/WorkbenchView.vue` — Code panel now mounts `<CodeTab />` (Issues/Kanban stay placeholders for T3/T4).

**Tests (TDD — red first)**
- `github-client.test.ts`: +4 (listBranches mapping/auth, getFileContent decode/ref/ssh). `github-routes.test.ts`: +5 (branches + content, auth/param validation, credential scoping).
- `github-api.spec.ts` (7), `github-tree.spec.ts` (6), `github-highlight.spec.ts` (18), `code-tab.spec.ts` (7): repos/branches/tree/content API wiring, tree shape + ordering, highlight token classes + XSS + per-line rendering, and CodeTab behavior (empty state, repo load, expand/collapse, file view with line numbers + `tok-keyword`, branch switch, error state).
