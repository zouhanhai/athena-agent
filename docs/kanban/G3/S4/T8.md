# G3.S4.T8: Local issue detail / edit / comments in Workbench

## Task

Currently the Issues tab renders issue titles as `<a href="issue.html_url" target="_blank">` — clicking
opens GitHub in a new tab. User wants full **local** issue management: view detail, edit, and comment
inside the platform (the AgentIDE vision), syncing back to GitHub.

## Backend — new GitHub APIs (server/src/github/client.ts + server/src/routes/github.ts)

Add to the GitHub client (all scoped to the employee's credential):
- `getIssue(credential, owner, repo, number)` → `GET /repos/{o}/{r}/issues/{n}` (title, body, state, labels, assignees).
- `getIssueComments(credential, owner, repo, number)` → `GET /repos/{o}/{r}/issues/{n}/comments`.
- `updateIssue(credential, owner, repo, number, input)` → `PATCH /repos/{o}/{r}/issues/{n}`
  (title, body, state, labels).
- `createIssueComment(credential, owner, repo, number, body)` → `POST /repos/{o}/{r}/issues/{n}/comments`.

Routes (scoped to the signed-in employee via their credential):
- `GET /api/github/repos/:owner/:repo/issues/:number` — detail + comments.
- `PATCH /api/github/repos/:owner/:repo/issues/:number` — update.
- `POST /api/github/repos/:owner/:repo/issues/:number/comments` — add comment.

## Frontend — IssuesTab local detail panel (web/src/components/IssuesTab.vue + web/src/api/github.ts)

- Clicking an issue no longer navigates; instead opens a **local detail panel** (side panel / drawer /
  expandable section) for that issue.
- Detail panel shows: rendered body (reuse `renderMarkdown` from `@/kb/markdown`), labels, assignees,
  state, and the comment thread (each comment = author + body + date).
- **Edit mode**: inline forms to edit title, body (markdown), state (open/close), and labels (pick from
  repo labels) — save calls the PATCH API.
- **Comment box**: textarea + submit → POST comment → refresh the thread.
- Reuse existing `fetchRepos`/`fetchIssues` patterns; add `fetchIssueDetail`, `updateIssue`, `addIssueComment`
  to `web/src/api/github.ts`.
