# G3.S5.T6: Collapsible table of contents (long docs)

## Task

The wiki page TOC (rendered by `markdown-it-table-of-contents` as a nested `<ul class="wiki-toc">`,
G3.S5.T5) is currently a **static flat list**. For long docs with hundreds of headings the TOC is a
wall of text. Make the sub-levels **collapsible** so the reader can expand/collapse nested sections.

Current TOC HTML structure (rendered):
```html
<div class="wiki-toc"><ul><li><a href="#main">Main</a><ul>
  <li><a href="#section-1">Section 1</a><ul><li><a href="#sub-1.1">Sub 1.1</a></li></ul></li>
  ...
```

## Decision (2026-08-09): no ready-made collapsible markdown-it TOC plugin exists
(markdown-it-table-of-contents / @mdit-vue/plugin-toc all emit a static nested list — none fold).
We already use `markdown-it-table-of-contents` which outputs a standard nested `<ul class="wiki-toc">`.
**Frontend JS accordion** (event delegation on the existing nested `<ul>`) is the lightest, dependency-free
approach. HTML `<details>/<summary>` would be more "native" but requires a custom markdown-it TOC
renderer (bigger change). Go with JS accordion.

## Implementation (prefer frontend JS/CSS in WikiView, not touching markdown.ts)

1. `web/src/views/WikiView.vue`: after the content is rendered (`renderedContent` / `v-html`), add a
   small script that walks `.wiki-toc li` elements. For each `li` that has a child `ul`, inject a
   collapse toggle (▸/▾) and wire a click handler that toggles the child `ul`'s visibility. Leaf items
   (no child `ul`) still navigate to their heading anchor.
   - Default: collapse deep levels (e.g. keep h1+h2 visible, collapse h3 and deeper), so long TOCs are
     compact; user clicks to expand.
   - Use event delegation on the existing content click or attach after `nextTick` when content changes.
2. `web/src/views/WikiView.vue` CSS: style the toggle indicators + collapsed state (e.g. muted color,
   cursor pointer, indent).
3. Tests: add a WikiView test that a TOC `li` with children has a toggle, toggling collapses/shows the
   child `<ul>`, and a leaf still links to its anchor. Keep all green (web `npx vitest run`,
   `npx vue-tsc --noEmit`).
