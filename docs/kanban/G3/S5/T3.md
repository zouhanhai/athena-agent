## Log

### 2026-08-08 — opencode (ses_f73c80a0b291c0c9)

Implemented real LightRAG status + chunk progress; no false done.

**Problem:** `ingestLightRag` marked the stage "done" the moment the POST
`/documents/text` 202 returned — but LightRAG processes asynchronously, so the
task lied about completion.

**Change (backend):**
- `server/src/kb/lightrag.ts`: added `getTrackStatus(trackId)` (GET
  `/documents/track_status/{track_id}` — per-submission real status with
  `chunks_count` / `error_msg`) and `getPipelineStatus()` (GET
  `/documents/pipeline_status` for the "Chunk N of M" log). `listDocuments`
  now also carries `chunks_count` / `error_msg`.
- `server/src/kb/lightrag-track.ts` (new): `evaluateTrack` maps a track's
  documents → pending/running/done/failed (any FAILED fails the submission,
  all must be PROCESSED for done); `parseChunkProgress` reads the latest
  "Chunk N of M" line; `LightRagTrackPoller` polls until terminal
  (interval 1500ms, timeout 10min → failed "timed out").
- `server/src/kb/ingest.ts`: `getLightRagTrackStatus` / `getLightRagPipelineStatus`
  delegations.
- `server/src/kb/tasks.ts`: the LightRAG stage now submits, keeps the
  `trackId`, and polls real status — stage stays "running" while the backend
  processes, only flips to done on `processed`, fails on `failed` / timeout.
  New `task.lightrag` field exposes `backendStatus`, `chunksProcessed`,
  `chunksCount`. "chunking" sub-step flips to done once the chunk total is
  known.

**Change (frontend):**
- `web/src/api/kb.ts` / `web/src/kb/ingest.ts`: `lightrag` field flows through.
- `web/src/views/UploadsView.vue`: LightRAG stage shows `chunk 12/182` while
  processing (from the pipeline log) and `182 chunks` once processed.

**Tests (TDD):** `server/test/kb/lightrag-track.test.ts` (new: evaluator,
chunk-log parser, poller incl. timeout + best-effort pipeline failure);
`server/test/kb/tasks.test.ts` (task stays ingesting while processing, chunk
progress surfaced, real backend failure surfaced, timeout → no false done,
retry re-polls); `server/test/kb/routes-ingest.test.ts` + `lightrag.test.ts`
(route-level + client polling). Server suite 478/478; web suite green (3
pre-existing unrelated failures in knowledge-view/add-data specs).
