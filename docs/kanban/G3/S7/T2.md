## Log

### 2026-08-08 — Audit + improvements (opencode, ses_20260808_g3s7t2)

**Design read (taste-skill 0.B):** product dashboard / dev-tool portal for technical
users, CALEO brand (orange `#ff6633` + navy `#2d3142` + sky `#69b3e7` + white),
TDesign component system + CALEO tokens. Dials: `DESIGN_VARIANCE 5` / `MOTION_INTENSITY 4` /
`VISUAL_DENSITY 6`. This is dashboard UI — only the applicable taste rules (typography /
spacing / hierarchy / anti-slop / motion) are applied, per skill §13.

**Audit findings (from `redesign-existing-projects` + `design-taste-frontend`):**

*Typography*
- A1. Body uses the browser-default system font stack (generic); page titles (20px) sit
  inside a bordered box on every page with no weight/tracking character.
- A2. Data numerals (chunk counters, node/link counts, relation weights, task badges,
  progress) render in proportional figures - no `tabular-nums`.
- A3. Page titles are uniform across Knowledge/Workbench/Wiki/Uploads (layout repetition);
  headers are bulky (16px 20px padding) for single-line toolbars.

*Layout / spacing / hierarchy*
- A4. Knowledge header (KnowledgeView.vue) is oversized now that the Add Data panel is
  gone: 20px title + padded box + wide controls = one tall empty band. Needs auto-compact.
- A5. All four page views use `height: calc(100vh - 48px)` / `100vh` shells - no `dvh`
  guard for mobile browser chrome.
- A6. Nested "border + shadow" card look repeats at 3 levels in Chat panel
  (participants box > agent-card) and Uploads (task-list-wrap > task-item).

*Color / surfaces*
- A7. Semantic colors hardcoded: error `#d54941`, success `#2f9e63` repeated in 12+ files -
  no `--caleo-error` / `--caleo-success` tokens; green fails contrast on dark surfaces.
- A8. Undefined tokens: `--caleo-hover` (GlobalChatPanel) and `--caleo-card-bg`
  (RegisterView / DeclarationCard / chat speaker logo) fall back to `#fff` / orange.

*Anti-slop (text)*
- A9. Em-dash `—` in Uploads URL placeholder and Issues empty state (`design-taste §9.G` ban).
- A10. Knowledge metaText chains two `·` separators (`local graph for "X" · N entities ·
  M links`) - middle-dot is rationed (max 1 per line, §9.F).

*Motion (emilkowalski `animate` skill)*
- A11. New chat messages mount instantly - no entry transition; a subtle fade+rise
  (state indication, occasional tier) would feel finished.
- A12. No shared easing token; ThemeToggle redefines its own `--caleo-ease-out`.

**Implemented (prioritized):**
1. **Knowledge header auto-compact** (A4): tightened padding/controls/title, meta below.
2. **Semantic color tokens** (A7/A8): `--caleo-error`, `--caleo-success`, `--caleo-hover`,
   `--caleo-card-bg` defined per theme; hardcoded colors replaced across views/components.
3. **Typography** (A1/A2/A3): tabular-nums on data numerals; page titles 16px / weight 600 /
   tighter tracking; consistent compact header spec on all four pages.
4. **Anti-slop text** (A9/A10): em-dash removed; knowledge meta single `·` separator
   (`"X" · N entities, M links`).
5. **Motion** (A11/A12): shared `--caleo-ease-out` token; chat message entry animation
   (fade + 4px rise, 200ms ease-out, `prefers-reduced-motion` respected).
6. **Viewport stability** (A5): `100dvh` fallback for app shell / pages / chat panel.
7. **Stale-test cleanup**: 6 pre-existing failures (chat/layout/uploads/workbench specs
   still asserting the Chat header text / userId field / Kanban nav item removed by
   earlier G3.S7 commits) updated to current UI. Suite now fully green (267/267).

Cross-checked with `animate` skill: all motion gated under `prefers-reduced-motion`,
transform/opacity only, named transition properties (no `transition: all`), durations
under 300ms, strong `cubic-bezier(0.23, 1, 0.32, 1)` ease-out.
