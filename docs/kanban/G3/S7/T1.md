# G3.S7.T1: Animated theme toggle (stars+moon deep / sun+cloud light)

## Task

Add an animated theme-toggle control as a slider under the Settings button. Deep (dark) theme shows stars + moon; light theme shows sun + cloud, with a tasteful animation on switch.

## Implementation

- Slider under the Settings button in the sidebar (not inside the settings panel)
- Deep = stars + moon icon; light = sun + cloud icon
- Animate the icon swap using the emilkowalski **animate** skill:
  - CSS transition (crossfade), ease-out curve `cubic-bezier(0.23,1,0.32,1)`, duration 150-250ms
  - Never `scale(0)`; crossfade + slight scale (0.9→1)
  - Respect `prefers-reduced-motion` (keep the state change, drop the transform)
- Wire to the existing theme store

## Recommended Skills (OpenCode)

- **animate** (emilkowalski/skills): build the toggle animation correctly
- **tdd** / **implement** / **code-review**

### 2026-08-08 — opencode (ses_20260808_g3s7t1)

Implemented `web/src/components/ThemeToggle.vue` per the emilkowalski **animate** skill.

- **Gate**: occasional frequency, purpose = *state indication* (making the theme switch legible).
- **Tool/properties**: CSS transitions on `opacity` + `transform` only; thumb slides via `translateX(32px)`, icon pairs crossfade `opacity 0/1` with a slight `scale(0.9→1)` (never `scale(0)`).
- **Curve/duration**: `--caleo-ease-out: cubic-bezier(0.23,1,0.32,1)`, 200ms (150–250ms range; UI < 300ms).
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` keeps the icon state change (gentle 150ms opacity crossfade) and drops the slide/scale transforms.
- **Icons**: dark/deep = `StarFilledIcon` + `MoonFilledIcon`; light = `SunnyFilledIcon` + `CloudFilledIcon`.
- **Wiring**: `role="switch"` slider calls `useThemeStore().toggle()` → `setMode` persists to `caleo-theme` and `App.vue`'s `applyTheme` watcher re-themes every page (existing wiring). Placed under the Settings button in `SidebarNav.vue`'s footer (outside the settings dialog).
- **Tests (TDD)**: `web/src/__tests__/theme-toggle.spec.ts` (default dark state + stars/moon, click flips store + persists + shows sun/cloud, external store changes reflected) and a placement test in `layout.spec.ts` (toggle sits below `.settings-trigger` in the footer). `vue-tsc` clean; full suite shows only 7 pre-existing unrelated failures (verified on base).
- **Feel-check**: crossfade/scale balance worth eyeballing in the DevTools animation inspector at 2–5× speed.
