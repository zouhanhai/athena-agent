# G3.S2.T9: Manual agent registration entry in the Agents panel

## Task

The Agents panel currently only lists **pending self-declarations** (`POST /api/agents/self-declare`).
If no agent has self-declared, the panel is empty and an admin can't register an agent manually. The
backend already has `POST /api/agents` (register with alias + owner_employee_id + capabilities +
logo_url + runtime) with NO auth gate, but the frontend never calls it.

Add a **manual registration entry**: a "Register agent" button in the Agents panel (`AgentManagement.vue`)
that opens a small form (alias, owner employee, logo picker, capabilities, runtime) and POSTs to
`/api/agents`.

## Implementation

1. Frontend `web/src/api/agents.ts`: add `createAgent(input)` → `POST /api/agents` (reuse `request`).
   Input mirrors `AgentCreateInput` (alias, owner_employee_id, logo_url?, capabilities, runtime?).
2. `web/src/components/AgentManagement.vue`: add a "Register agent" button + form (alias, owner email/id,
   logo from the logos list, capabilities JSON or structured fields, runtime). On submit call `createAgent`,
   then refresh the agent list. Only show for admins (`auth.employee?.role === "admin"`).
3. Owner employee: provide a dropdown of employees (GET /api/employees) so the admin picks the owner.
4. Tests: createAgent helper + manual registration flow; keep all green (web `npx vitest run`,
   `npx vue-tsc --noEmit`; server tests).
