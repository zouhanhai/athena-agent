# G3.S2.T5: Profile + Agents settings — name/logo/GitHub + agent management in Settings dialog

## Task

The Settings dialog (`web/src/components/SettingsPanel.vue`) currently only has a **Theme** switch.
Add a **Profile** section so a signed-in employee can update their own:
- display name
- logo (from the animal logo set)
- GitHub credential (token or SSH) — **currently GitHub is only settable at registration**, there is no way to add/change it afterward.

**Also** consolidate the standalone **Agents tab** (`/agents` → `AgentRegistrationView.vue`, agent declaration/registration management) into the Settings dialog, and remove Agents from the sidebar (like Kanban was consolidated into Workbench).

## Problem

- Backend `PUT /api/employees/:email` (server/src/routes/employees.ts) only accepts `display_name` / `logo_url` / `role` — **no `github_credential`**.
- `github_credential` is only written during invitation registration (`registerInvitedEmployee`).
- SettingsPanel has no Profile section and no agent management; Agents is a separate sidebar item.

## Implementation

1. Backend: extend the employee update path to accept `github_credential` (encrypted at rest via the existing SecretCipher), OR add a scoped `PUT /api/me` / `PATCH /api/me/github` for the current employee. Must re-encrypt/overwrite, never return the secret.
2. Frontend: add a Profile section in SettingsPanel (display name, logo picker, GitHub editor → save → toast + update auth store).
3. Consolidate agent management into Settings (move/reuse AgentRegistrationView contents — self-declared agents + register with alias/logo), remove Agents sidebar item and /agents route.
4. Tests: backend employee-update (github_credential encrypted + persisted), frontend settings profile + agents-in-settings.
