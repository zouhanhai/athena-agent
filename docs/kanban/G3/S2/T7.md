# G3.S2.T7: Logo upload UI + hide in-use logos + drop SSH

## Task

Three UI/logic improvements to the logo + GitHub credential handling:

1. **Logo upload**: backend `POST /api/logos` (multipart) already exists but the frontend never calls it.
   Add an upload control to the logo picker in **SettingsView** (and RegisterView) so a signed-in user can
   upload a custom logo image (png/jpg/webp). After upload it appears in the picker.
2. **Hide in-use logos**: logos already chosen by an agent or employee should not be shown as available
   (avoid two people/agents picking the same logo). Need a backend signal of which logo_urls are in use
   (aggregate agent.logo_url + employee.logo_url), and the picker filters those out.
3. **Drop SSH, token-only**: GitHub REST access is token-only (see `server/src/github/client.ts:170`
   — SSH keys cannot auth the REST API and are rejected). Remove the SSH option from the register +
   settings GitHub credential forms; keep only "Personal access token". Backend already accepts any token
   string (no ghp_/github_pat_ prefix check), so both Classic and Fine-grained PATs work — document the
   required scopes in the UI hint.

## Implementation

1. Frontend: add upload button in `SettingsView.vue` logo picker (+ `RegisterView.vue`): file input →
   `POST /api/logos` (multipart file) → refresh logo list. Reuse `listLogos()` from `@/api/agents`.
2. Backend: expose in-use logo_urls (e.g. `GET /api/logos/in-use` → `{ urls: string[] }` from agents +
   employees), OR filter server-side in `GET /api/logos` (add `?exclude-in-use=1`). Prefer server-side so
   the picker just gets available logos.
3. Frontend: logo picker filters out in-use logos; show a hint "used by another agent/employee".
4. Frontend: remove SSH option from GitHub credential forms (register + settings). Update placeholder +
   hint to describe Classic (`repo` scope) vs Fine-grained (repo-level Contents/Issues/PR read).
5. Tests: upload flow (mock POST /api/logos); in-use logos excluded from picker; token-only form
   (no SSH option). Keep all green (web `npx vitest run`, `npx vue-tsc --noEmit`; server tests).
