# G3.S2.T6: Settings as standalone sidebar tab + sidebar reorder + Output placeholder

## Task

G3.S2.T5 turned Settings into a **dialog** (`SettingsPanel.vue` opens a `t-dialog` from the sidebar footer)
containing Profile + Agents + Theme. Change Settings to a **dedicated sidebar tab** (full page), remove the
dialog, reorder the sidebar to `Knowledge → Wiki → Workbench → Uploads → Output → Settings`, and add an
**Output placeholder page** (full Output generation is M5).

Content of the Settings page:
- **Profile** section (display name / animal logo / GitHub credential) — reuse the exact form/logic
  from `SettingsPanel.vue`.
- **Agents** section (`AgentManagement.vue`) — reuse as-is.
- **No Theme section** on the page — the sidebar `ThemeToggle` remains the single theme switch
  (the in-dialog Theme section is removed).

## Implementation

1. Create `web/src/views/SettingsView.vue` — a full page containing the Profile + Agents sections
   (lift the markup + logic out of `SettingsPanel.vue`'s `t-dialog` body; drop the dialog wrapper and the
   Theme section). Layout consistent with other views (`.wiki-body`-style panel on a `--caleo-surface` card).
2. Create `web/src/views/OutputView.vue` — a placeholder page ("Output — coming in M5") so the nav item
   has a real target.
3. Routes in `web/src/router/index.ts`: add `/settings` → `SettingsView.vue` and `/output` → `OutputView.vue`.
4. `web/src/components/SidebarNav.vue`: reorder `navItems` to
   `Knowledge(/knowledge) → Wiki(/wiki) → Workbench(/workbench) → Uploads(/uploads) → Output(/output) → Settings(/settings)`
   (Settings uses `SettingIcon`); **remove** `<SettingsPanel />` from the footer (keep `<ThemeToggle />`).
5. Remove/stop using `SettingsPanel.vue` (move its logic into SettingsView; keep `AgentManagement.vue` as a child).
6. Tests: sidebar shows the 6 nav items in the exact order; /settings renders Profile + Agents (no Theme
   section); /output renders the placeholder; SettingsPanel dialog trigger gone from the footer. Keep all
   existing tests green (web `npx vitest run`, `npx vue-tsc --noEmit`).
