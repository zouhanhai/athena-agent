# G3.S3.T3: Agent cards + speak-toggle + add agent/employee

## Task

Agent cards above chat (from S1) with speak-toggle; entry to add agents/employees. Hooks fire on card interactions.

## Implementation

- Agent card component (logo/alias/capabilities/speak-toggle)
- **X button on each card to remove the agent from the conversation** → fires `onAgentLeft`
- Add-agent entry (from S1), add-employee entry (from S2)
- Speaker logo on each message
- **Hooks on card interactions (Vercel-inspired, §4.3)**:
  - `onAgentJoined`: add agent card → inject page context + notify + show card
  - `onSpeakToggleChanged`: flip speak-toggle → update agent's speak permission
  - `onAgentLeft`: **X button** removes agent card → clean up context + notify
