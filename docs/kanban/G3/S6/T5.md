# G3.S6.T5: GitHub integration (browse + ops)

## Task

GitHub REST with per-user credential: browse (repos/tree/PR/Issue) + ops (open PR/edit/merge).

## Implementation

- routes/github.ts
- browse: repos/tree/PR/Issue
- ops: open PR, edit file (PUT contents), merge PR
- confirm flow for mutate ops

## Log
[2026-08-08] opencode completed GitHub integration (browse + ops) — TDD, 37 new tests (367→404 pass):
  - **`server/src/github/client.ts`** — `GitHubApi` extended (browse + ops, all per-user token-scoped):
    `listTree` (recursive git tree; resolves default branch / branch / tag / sha ref),
    `listPulls`, `listIssues` (open, per_page=100), `openPull` (POST /pulls),
    `editFile` (PUT /contents/{path}, base64 content), `mergePull` (PUT /pulls/{n}/merge).
    Shared `request()` helper centralizes token auth (Bearer), 401/403→`GithubAuthError`,
    ssh→`GithubCredentialUnsupportedError`, non-2xx→error with `status`.
  - **`server/src/github/ops.ts`** — confirm-flow store: `GITHUB_OP_KINDS`
    (open_pull/edit_file/merge_pull), `PendingGithubOp` (id, employee_email, kind, input,
    summary, created_at, expires_at), `MemoryGithubOpStore` with 30-min TTL
    (expired→`GithubOpExpiredError`, unknown→`GithubOpNotFoundError`).
  - **`server/src/routes/github.ts`** — browse scoped to the signed-in user's credential:
    `GET /api/github/repos/:owner/:repo/tree?ref=`, `/pulls`, `/issues`. Mutate ops go through
    a **confirm flow** (employee watches — no direct mutate endpoint):
    `POST /api/github/ops` → 201 pending op (+summary), `GET /api/github/ops/:op_id`,
    `POST /api/github/ops/:op_id/confirm` → executes ONLY here, `DELETE /api/github/ops/:op_id`.
    Ops are owned by `employee_email`: get/confirm/cancel return 403 for other employees;
    confirm 404 on already-consumed/unknown op; expired → 410.
  - **`server/src/app.ts`** — `BuildAppOptions.ops` (default `MemoryGithubOpStore`) wired to the routes.
  - Tests: `github-client.test.ts` (+13), `github-ops.test.ts` (new, 6),
    `github-routes.test.ts` (+18 browse/ops/confirm-scoping). Full suite 404 pass / 0 fail;
    `typecheck` + `build` clean.
  - Acceptance criteria met: browse works, open PR/edit/merge works, confirm flow, scoped to user.
