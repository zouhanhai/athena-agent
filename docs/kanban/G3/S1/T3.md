### 2026-08-08 — opencode (ses_49f21e7a3c8b5d1f) — done

Implemented the logo system (TDD, all 195 server tests pass + typecheck clean):

- **Animal logo set (consistent style)**: `server/src/agents/logos.ts` — `OpenRouterLogoClient`
  calls `POST /api/v1/images` (gemini-3.1-flash-image) with the owl logo
  (`web/public/athena-logo-ai.png`) as a style-reference image; `FileLogoStore` persists
  assets + an `index.json` manifest under `web/public/logos/`. Real set generated:
  fox(teal), eagle(amber), lion(crimson), wolf(indigo), dolphin(blue), raven(violet) —
  committed as `.jpg` assets. Regenerable idempotently via `npm run logos:generate`
  (`server/scripts/generate-logos.ts`). Generation is a build-time op (committed assets),
  not runtime auto-gen, to keep the server deterministic and tests network-free.
- **Self-upload + agent wiring**: `POST /api/logos` (multipart `file`, optional `alias`)
  stores the image under `web/public/logos/uploads/` and, when `alias` is given, sets the
  agent's `logo_url` (404 if unknown). Validates mimetype allowlist + content magic bytes.
- **List API**: `GET /api/logos` returns generated + uploaded logos.
- Wired into `buildApp` via `defaultLogoStore()` (owl reference + real client).

Tests: `server/test/logos.test.ts` (store), `logos-routes.test.ts` (API), `logos-default-store.test.ts`
(committed set via default app). Routes: `server/src/routes/logos.ts`.
