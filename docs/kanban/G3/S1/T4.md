### 2026-08-08 — done (opencode, ses_8f3b2c5e7d91a406)

**Implemented**

- `POST /api/agents/self-declare` — agent auto-fills its own capabilities + runtime
  (`agent_id`, `capabilities`, `runtime?`); no alias/logo. Returns a pending declaration.
- `GET /api/agents/declarations` — list pending self-declarations.
- `POST /api/agents/register-declaration/:id` — employee confirms with alias + owner +
  logo; atomically creates the agent (declaration capabilities/runtime) and consumes the
  declaration. 404 unknown declaration, 409 alias conflict (declaration stays pending).
- Registry (`AgentRegistry`): `submitDeclaration`, `listDeclarations`,
  `registerDeclaration` implemented on both `MemoryAgentRegistry` and
  `PostgresAgentRegistry` (new `agent_declarations` table, transactional register).
- **Agent registration UI** (`/agents`): employee reviews a card per declaration
  (agent id, runtime, system/specialty/mcp/tools/skills), picks alias + owner + logo
  (generated animal set + Athena owl default), confirms → agent created, card removed.
  Wired into the T1 registry; new sidebar nav item (Usergroup icon).
