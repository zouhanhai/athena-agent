# G3.S1.T5: Consistent transparent animal logos via krea (per-animal custom prompts)

## Task

Regenerate the animal logo set with a consistent cute-geometric style matching the original owl logo, using `krea/krea-2-medium-turbo` and a **per-animal custom prompt**. Transparent outer background with the animal face preserved opaque (so it looks clean on both light and dark themes).

## Problem (why this ticket)

The previous 6 logos (fox/eagle/lion/wolf/dolphin/raven) were generated with a **generic template** that only swapped `{animal}` + `{color}`. This let the model free-associate — e.g. fox became a Redpanda-style icon that looks broken on dark backgrounds. Each animal needs a **custom prompt** describing its own features (ears, snout, mane, etc.), like the owl's "cute, small ears, glasses" direction.

Also, image models (krea/qwen) don't output true alpha transparency through OpenRouter — the outer background must be **cut via precise flood-fill** (only the outer connected background → transparent; interior face preserved opaque).

## Implementation

1. Rewrite `ANIMAL_LOGO_SET` + `logoPrompt` in `server/src/agents/logos.ts`:
   - Use `krea/krea-2-medium` as the image model (verified better quality than turbo; both output white bg via OpenRouter so post-processing cut is required)
   - Give each animal a **custom prompt** (cute geometric flat mascot, matching owl): e.g.
     - fox: pointy ears, white cheek patches
     - eagle: sharp beak, wings
     - lion: golden mane, round face
     - wolf: pointed ears, snout
     - dolphin: smooth curved fin
     - raven: pointed beak
   - Emphasize: flat geometric vector, transparent background, isolated subject, no text, consistent style with reference owl
2. Post-process each generated PNG: cut only the outer connected white background to transparent (preserve animal face opaque)
3. Regenerate + save as PNG under `web/public/logos/`, update `index.json`
