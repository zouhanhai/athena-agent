# G3.S8.T1: Remove Add Data from Knowledge + topic/localized graph views

## Task

Clean up the Knowledge Graph page: drop the duplicated Add Data panel and make the graph view usable when there are 1000+ nodes (topic-only or search-node local subgraph).

## Implementation

In `web/src/views/KnowledgeView.vue`:

1. **Remove Add Data**: delete the `showAddData` toggle button, the `.add-data-panel` block (drop-zone, URL row, task list), and related unused script state (`showAddData`, `fileInput`, `dragging`, `urlInput`, `useIngestTasks`, ingest helpers, `friendlyError`, etc.). Ingestion stays on the Uploads page.
2. **Default view**: do not load all nodes on mount. Default to a topic filter or a compact/empty state.
3. **Search-node local graph**: add the ability to search for a node and show its local neighborhood (node + 1-2 hop relations via `nodeRelations`), instead of the whole 1000+ node graph. Reuse `searchKnowledge` or a node lookup.

Follow TDD. Use codegraph_explore. When done: update ticket status=done + Log, git add/commit/push. Report completion.
