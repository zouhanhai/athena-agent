# G3.S8.T2: Knowledge graph — fix type/topic misclassification, canvas fit, search

## Task

Fix several Knowledge graph issues found during testing.

## Problems (user-reported)

1. **GroupReporting doc classified as `comparison` type** — wrong. Root cause: `localClassify` in `server/src/kb/ingest.ts` matches `comparison` first (`\b(vs\.?|comparison|compare|differences?|alternatives?)\b`), and the consolidation/financial report text happens to contain such words. The comparison rule is too eager / ordering wrong.
2. **No topic for GroupReporting** — `localTopic` only recognizes fixed keywords (sommerseminar/summer-school/conference/workshop/retreat/meetup). GroupReporting matches none → `topic: undefined`. Decide: a fallback topic (e.g. filename-derived or `untitled`) so it groups somewhere, OR explicitly allow no-topic files under the type dir.
3. **Canvas shows one dot on topic load** — v-network-graph `autoPanAndZoomOnLoad: "fit-content"` + ForceLayout places all nodes at origin initially; fit computes from the collapsed initial layout so it looks like a single point. Need to fit AFTER the layout settles (e.g. `fitToContent()` after forceLayout's first frame / requestAnimationFrame) or disable initial fit and let layout run.
4. **Node search doesn't work** — `loadNodeGraph` calls `getGraph(query)` → `/api/kb/graph?label=`. LightRAG `/graphs?label=` may not match by exact node label (fuzzy / different match). Need exact node lookup (or list nodes, find match) so searching a node opens its 1-2 hop local graph.
5. **Sommerseminar shows only 15 nodes / 21 links** — verify this is accurate (few docs) vs. a topic-mapping gap in `filterGraphByTopic` / `buildTopicMap` (nodes whose source file maps to the topic via wiki frontmatter). If docs are few, confirm count is correct; if mapping is incomplete, fix it.

## Implementation

- `server/src/kb/ingest.ts`: reorder/harden `localClassify` (comparison after entity/concept, or require explicit comparison keywords in title, not any content match); improve `localTopic` fallback.
- `web/src/views/KnowledgeView.vue`: fix canvas fit (fit after force layout settles); fix node search to find exact node then show local subgraph.
- Verify Sommerseminar node/link count against LightRAG data.
